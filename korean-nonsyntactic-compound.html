비통사적 합성어란 무엇인가 — 일반 통사 규칙을 벗어난 합성

비통사적 합성어는 두 어기의 결합이 일반적인 통사적 구를 이루는 방식과 다른 합성어입니다. ‘어미가 빠졌다’고만 외우기보다 실제 문장에서 가능한 결합인지 비교해야 합니다.

1. 비통사적 합성어의 뜻 — 통사적인 구와 다른 방식으로 결합한 합성어

우리말샘은 비통사적 합성어를 두 어기의 결합이 통사적인 구를 이루는 방식과 다른 합성어로 설명합니다. 즉 둘 이상의 어근이 결합해 하나의 단어가 되었다는 점에서는 일반 합성어와 같지만, 그 내부 결합 방식이 문장이나 구에서 보통 허용되는 방식과 다릅니다.

합성어 + 일반 통사 규칙과 다른 결합 → 비통사적 합성어
핵심
비통사적 합성어는 “무엇이 빠졌는가”보다 두 어기가 문장에서도 같은 방식으로 결합할 수 있는가를 보는 개념입니다.

2. ‘비통사적’이라는 말의 의미 — 문장에서는 그대로 만들기 어려운 구조

일반 문장에서는 용언과 용언을 연결할 때 연결 어미가 필요하고, 용언이 명사를 꾸밀 때는 관형사형 어미를 사용합니다. 그런데 일부 합성어에서는 이런 일반적인 결합 방식과 다른 구조가 나타납니다.

일반적인 통사 구성비통사적 결합의 예
들- + -어 + 가-밉- + 보-
뛰- + -어 + 놀-뛰- + 놀-
접는 + 칼접- + 칼 → 접칼
볼록한 + 거울볼록 + 거울 → 볼록거울

따라서 형태소가 둘 이상이라는 사실만으로 비통사적 합성어를 판별할 수는 없습니다. 결합 관계를 함께 확인해야 합니다.

3. 밉보다 — 앞 용언 어간 뒤에 어미가 없는 직접 결합

국립국어원 온라인가나다는 ‘밉보다’를 비통사적 합성어라고 설명합니다. 앞부분 ‘밉-’은 용언 어간인데 그 뒤에 연결 어미가 결합하지 않고 곧바로 뒤 어간 ‘보-’와 이어집니다.

밉- + 보- + -다 → 밉보다

일반적인 문장 구성에서는 두 용언 어간이 이렇게 바로 이어지는 방식이 보통의 연결 방식이 아닙니다. 이 때문에 ‘밉보다’는 비통사적 합성어의 명확한 예가 됩니다.

4. 뛰놀다 — 어간과 어간이 연결 어미 없이 바로 결합

국립국어원의 상담 사례 모음은 ‘뛰놀다’를 비통사적 합성어로 설명하면서, 그 이유를 어간 ‘뛰-’와 어간 ‘놀-’이 적절한 연결 어미 없이 바로 결합했기 때문이라고 밝힙니다.

뛰- + 놀- + -다 → 뛰놀다

일반 문장에서는 ‘뛰어 놀다’처럼 연결 어미 ‘-어’가 필요합니다. 합성어 내부에서는 그 일반적 통사 구성이 그대로 나타나지 않으므로 비통사적이라고 보는 것입니다.

용언+용언의 첫 판별법
두 어간 사이에 일반적인 연결 어미가 참여하는지, 아니면 어간끼리 바로 결합하는지 확인합니다.

5. 접칼 — ‘접는 칼’과 다른 방식으로 결합한 경우

우리말샘이 제시하는 대표적인 비통사적 합성어 가운데 하나가 ‘접칼’입니다. 일반 구에서는 동사 ‘접다’가 명사 ‘칼’을 꾸미려면 ‘접는 칼’처럼 관형사형이 필요합니다.

일반 구: 접- + -는 + 칼 → 접는 칼
합성어: 접- + 칼 → 접칼

‘접-’과 ‘칼’이 관형사형 어미 없이 직접 결합한 구조는 일반 통사적 구와 다르므로 비통사적 합성어로 설명됩니다.

6. 볼록거울 — 부사가 명사를 직접 꾸미는 결합

국립국어원은 ‘볼록거울’을 비통사적 합성어로 볼 수 있다고 설명합니다. ‘볼록’은 사전에서 부사로 제시되는데, 일반 문장에서 명사를 꾸밀 때는 ‘볼록한 거울’처럼 관형어 구성이 자연스럽습니다.

통사적인 구: 볼록한 거울
합성어: 볼록 + 거울 → 볼록거울

부사와 명사가 직접 결합하는 방식은 일반적인 명사 수식 방식과 다르다는 점이 판별 근거입니다.

7. 오르내리다 — ‘오르고 내리다’와 다른 내부 결합

우리말샘은 ‘오르내리다’를 비통사적 합성어의 예로 제시합니다. 일반 구라면 ‘오르고 내리다’처럼 연결 어미가 필요하지만, 합성어에서는 ‘오르-’와 ‘내리-’가 일반적인 구 구성과 다른 방식으로 하나의 단어를 이룹니다.

오르고 내리다 ≠ 오르내리다의 내부 결합 방식

여기서 중요한 점은 단어의 뜻이 아니라 어기 사이의 문법적 연결 방식입니다.

8. 통사적 합성어와 비교 — 같은 합성어라도 결합 규칙이 다르다

구분결합 방식대표 예
통사적 합성어일반적인 문장·구 구성 방식과 같음들어가다, 신나다
비통사적 합성어일반적인 문장·구 구성 방식과 다름밉보다, 뛰놀다, 접칼, 오르내리다

따라서 통사적/비통사적 구분은 합성어 여부를 판단한 뒤에 하는 두 번째 분류입니다. 둘 다 기본적으로는 둘 이상의 어근이 결합한 합성어입니다.

9. ‘어미가 생략됐다’고만 설명하면 안 되는 이유

비통사적 합성어를 공부할 때 흔히 “중간의 어미가 생략된 합성어”라고 외우지만, 이는 일부 사례만 설명합니다. ‘밉보다’, ‘뛰놀다’처럼 용언 어간끼리 직접 결합하는 경우에는 도움이 되지만, ‘볼록거울’처럼 품사 사이의 일반적인 수식 관계 자체가 다른 경우도 있기 때문입니다.

비통사적 = 어미 생략으로 단순화하지 마세요.
최종 기준은 일반적인 통사적 구 구성과 같은지 다른지입니다.

10. 직접 구성 요소가 중요한 이유 — 마지막 결합 관계부터 본다

복잡한 합성어는 내부의 모든 형태소를 한꺼번에 늘어놓기보다 마지막에 직접 결합한 두 덩어리를 먼저 봐야 합니다. 합성어의 통사적·비통사적 성격은 어떤 요소들이 최종 단계에서 어떤 관계로 결합했는지와 밀접합니다.

분석 순서
① 합성어인지 확인 → ② 마지막 직접 구성 요소를 찾기 → ③ 그 둘이 일반적인 구를 이루는 방식인지 비교 → ④ 경계 사례는 교과서 기준 확인.

11. 판정이 갈리는 경계 사례 — 깨물다·건너뛰다처럼 두 분석이 가능한 말

비통사적 합성어의 범위는 모든 문법 연구에서 완전히 동일하지 않습니다. 국립국어원은 ‘깨물다’를 ‘깨- + 물-’의 어간 직접 결합으로 보면 비통사적 합성어로 볼 수 있지만, ‘깨- + -어 + 물-’에서 형태가 줄어든 것으로 보면 통사적 합성어로도 볼 수 있다고 설명합니다.

‘건너뛰다’ 역시 ‘건너- + 뛰-’의 직접 결합으로 볼 수도 있고 ‘건너- + -어 + 뛰-’로 분석할 수도 있어 두 견해가 가능합니다.

경계 사례는 단정하지 않습니다.
국립국어원도 합성어 유형에는 견해차가 있을 수 있다고 안내하며, 학생에게는 교과서의 설명을 따를 것을 권합니다.

12. 실전에서 비통사적 합성어를 판별하는 네 단계

1합성어 확인둘 이상의 어근이 실제로 단어 형성에 참여했는지 봅니다.
2직접 구성 요소 찾기마지막에 결합한 두 어기나 단위를 나눕니다.
3일반 구와 비교연결 어미·관형사형·조사 등 보통 문장 구성에서 필요한 요소를 확인합니다.
4견해차 확인축약·역사적 형성 등 다른 분석이 가능하면 교과서·사전을 우선합니다.
  • 비통사적 합성어도 먼저 합성어입니다.
  • ‘밉보다’는 앞 용언 어간 뒤에 연결 어미가 없이 결합합니다.
  • ‘뛰놀다’는 어간과 어간이 직접 결합합니다.
  • ‘접칼’은 일반적인 ‘접는 칼’과 다른 결합을 보입니다.
  • ‘볼록거울’은 일반적인 ‘볼록한 거울’과 다른 수식 구조를 보입니다.
  • 통사적·비통사적 구분은 의미보다 형식적 결합 관계를 봅니다.
  • ‘어미 생략’ 하나로 모든 사례를 설명하지 않습니다.
  • 경계 사례는 교과서의 분석 기준을 우선합니다.

13. 한눈에 정리 — 문장에서 같은 방식으로 결합할 수 있는지 묻는다
