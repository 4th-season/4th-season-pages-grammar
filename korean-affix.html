접사란 무엇인가 — 접두사와 접미사가 만드는 의미와 품사 변화

접사는 어근이나 단어에 붙어 새로운 단어를 만드는 요소입니다. 앞에 붙으면 접두사, 뒤에 붙으면 접미사입니다. 하지만 ‘앞·뒤에 붙는다’만으로는 부족합니다. 핵심은 새 단어를 만들고 있는가입니다.

1. 접사의 정확한 정의 — 어근이나 단어에 붙어 새로운 단어를 만드는 요소

표준국어대사전은 접두사를 어근이나 단어의 앞에 붙어 새로운 단어가 되게 하는 말, 접미사를 어근이나 단어의 뒤에 붙어 새로운 단어가 되게 하는 말로 정의합니다. 둘을 합쳐 접사라고 합니다.

접두사 + 어근 → 새 단어　/　어근 + 접미사 → 새 단어

여기서 가장 중요한 말은 ‘앞’이나 ‘뒤’가 아니라 새로운 단어입니다. 접사는 문장 속에서 단어에 잠깐 붙는 요소가 아니라 단어의 내부 구성에 참여하는 요소입니다.

접사 판별의 첫 질문
“이 요소가 결합하면서 새로운 어휘 항목이 만들어졌는가?”를 먼저 봅니다. 단순히 앞이나 뒤에 놓였다는 이유만으로 접사라고 할 수는 없습니다.

2. 접두사와 접미사 — 위치는 다르지만 둘 다 단어 형성 요소다

접두사어근이나 단어의 앞에 붙습니다.
풋- + 고추 → 풋고추
맨- + 손 → 맨손
신- + 도시 → 신도시
접미사어근이나 단어의 뒤에 붙습니다.
덮- + -개 → 덮개
사랑 + -하- → 사랑하다
바둑 + -이 → 바둑이

학교 문법에서는 접두사와 접미사를 먼저 위치로 구분하지만, 실제 분석에서는 각 접사가 어떤 말에 붙는지, 어떤 의미나 문법적 성격을 더하는지까지 함께 확인해야 합니다.

3. 접두사가 하는 일 — 주로 의미를 더하거나 범위를 제한한다

접두사는 대체로 어근이나 단어의 기본 품사를 그대로 두면서 의미를 더하거나 범위를 제한합니다. ‘풋고추’의 ‘풋-’은 덜 익었다는 뜻을, ‘맨손’의 ‘맨-’은 다른 것이 덧붙지 않았다는 뜻을 보탭니다.

파생어접두사어근추가되는 의미
풋고추풋-고추덜 익은, 처음 나온
맨손맨-손다른 것이 없는
신도시신-도시새로운
접두사는 ‘꾸며 주는 말’과 같지 않습니다.
접두사는 단어 내부에 결합해 새 단어를 만들고, 관형사 같은 독립 단어는 문장 구성 성분으로 참여해 뒤의 체언을 꾸밉니다.

4. 접미사가 하는 일 — 의미를 더하고 때로는 품사를 바꾼다

접미사는 어근이나 단어 뒤에 붙어 새 단어를 만듭니다. 이 과정에서 단순히 의미만 더할 수도 있고, 새 단어의 품사를 바꾸기도 합니다.

덮- + -개 → 덮개동작 의미를 가진 어근에 사물 이름을 만드는 접미사가 붙어 명사가 됩니다.
사랑 + -하- → 사랑하다명사 ‘사랑’에 동사를 만드는 접미사가 결합해 동사가 됩니다.

‘사랑하다’를 형태소까지 나누면 사랑 + -하- + -다로 분석합니다. 여기서 ‘-하-’는 단어를 만드는 접사이고 ‘-다’는 활용을 나타내는 어미입니다.

5. 접미사는 언제 품사를 바꾸는가 — 파생 결과의 품사를 확인한다

접미사 가운데에는 결합 전과 결합 후의 품사를 바꾸는 것이 있습니다. 예를 들어 ‘사랑’은 명사지만 ‘사랑하다’는 동사입니다. 이런 접미사는 파생어의 문법적 성격까지 바꾸는 데 참여합니다.

사랑(명사) + -하-(동사 파생 접미사) + -다(어미) → 사랑하다(동사)

따라서 접미사의 기능을 설명할 때는 “뒤에 붙는다”에서 멈추지 않고 결합 전후의 품사가 같은지 달라졌는지를 확인하면 좋습니다.

품사 변화 확인법
접사를 떼기 전의 어근·단어가 어떤 품사인지, 접사가 붙어 완성된 파생어가 어떤 품사인지 차례로 비교합니다.

6. 모든 접미사가 품사를 바꾸는 것은 아니다

접미사는 품사를 바꾸는 것도 있고 바꾸지 않는 것도 있습니다. 국립국어원은 ‘바둑이’의 ‘-이’를 접미사로 설명하면서, 접미사 가운데에는 품사를 바꾸지 않는 것도 있다고 분명히 안내합니다.

예결합 전결합 후품사 변화
사랑 + -하- → 사랑하다명사동사있음
바둑 + -이 → 바둑이명사명사없음
“접미사 = 품사를 바꾸는 요소”라고 외우면 틀릴 수 있습니다.
품사 변화는 접미사가 가질 수 있는 기능 중 하나이지 모든 접미사의 필수 조건은 아닙니다.

7. 접사와 관형사·독립 단어의 차이 — ‘새’와 ‘신-’을 비교하면 선명하다

국립국어원은 관형사 ‘새’와 접두사 ‘신-’을 비교해 설명합니다. ‘새 집’의 ‘새’는 문장에서 독립적인 관형사로서 뒤의 명사 ‘집’을 꾸밉니다. 반면 ‘신도시’의 ‘신-’은 ‘도시’에 붙어 하나의 새로운 단어를 만드는 접두사입니다.

새 집‘새’ = 관형사
문장 구성 성분으로 참여
뒤의 명사와 띄어 씀
신도시‘신-’ = 접두사
단어 내부의 형성 요소
뒤의 어근과 붙여 씀

따라서 의미가 비슷하다고 같은 문법 단위인 것은 아닙니다. 문장 속 독립 단어인지, 단어 내부의 형성 요소인지를 확인해야 합니다.

8. 접사와 어미의 차이 — 새 단어를 만드는가, 같은 단어를 활용시키는가

접미사와 어미는 모두 용언 뒤쪽에서 보일 수 있어 자주 혼동됩니다. 차이는 기능입니다. 접사는 새 단어를 만들고, 어미는 이미 존재하는 용언을 문장 속에서 활용하게 합니다.

구분접사어미
핵심 기능새 단어 형성활용
예사랑 + -하- → 사랑하-사랑하- + -다/-고/-니
결과새 어휘 항목같은 단어의 다른 활용형
사랑하다 = 사랑 + -하- + -다
‘-하-’는 동사를 만드는 접미사이고, ‘-다’는 종결 어미입니다. 같은 단어 안에서도 단어 형성과 활용의 두 층위가 이어질 수 있습니다.

9. 접사에는 의미가 없는가 — 형식 형태소라는 말과 ‘의미 없음’은 다르다

접사를 형식 형태소로 분류한다고 해서 모든 접사가 의미가 없다는 뜻은 아닙니다. 국립국어원은 ‘맨-’, ‘풋-’, ‘-꾼’처럼 어휘적인 의미를 담는 접사도 많다고 설명합니다.

접사를 형식 형태소로 보는 일반적 기준은 새 단어를 만드는 문법적 기능에 초점을 둔 것입니다. 따라서 접사의 실제 의미 성격은 하나로 단순화하지 않는 것이 좋습니다.

접사 = 의미 없는 조각이 아닙니다.
접사는 문법적 기능을 수행하면서 동시에 구체적인 어휘 의미를 더할 수도 있습니다.

10. 생산성과 사전 등재 — 접사가 붙은 말이 모두 사전에 따로 실리지는 않는다

접사는 새로운 단어를 만드는 능력을 가질 수 있습니다. 특히 생산성이 높은 접사는 새로운 환경에서도 계속 파생어를 만들어 냅니다. 그러나 그렇게 만들어진 모든 파생어가 표준국어대사전에 개별 표제어로 등재되는 것은 아닙니다.

국립국어원은 생산적인 접사가 붙어 생성된 파생어는 사전 편찬에서 선별적으로 등재한다고 설명합니다. 따라서 “사전에 없으니 접사가 아니다”라고 판단해서는 안 됩니다.

사전 등재 여부와 문법적 형성 가능성을 구분해야 합니다.
접사의 생산성이 높을수록 실제 언어 사용에서는 사전에 따로 실리지 않은 파생어도 만들어질 수 있습니다.

11. 실전에서 접사를 판별하는 순서

1결합 위치 확인어근이나 단어 앞인지 뒤인지 봅니다. 앞이면 접두사 후보, 뒤면 접미사 후보입니다.
2새 단어 여부 확인결합 결과가 하나의 새로운 단어를 이루는지 봅니다.
3기능 확인의미를 더하거나 제한하는지, 품사를 바꾸는지 확인합니다.
4다른 단위와 비교관형사·조사·어미처럼 문장이나 활용에서 쓰이는 다른 요소와 구별합니다.
  • 접사는 단어 형성 요소입니다.
  • 접두사는 앞, 접미사는 뒤에 붙습니다.
  • 접두사는 주로 의미를 더하거나 범위를 제한합니다.
  • 접미사는 품사를 바꿀 수도 있지만 반드시 바꾸는 것은 아닙니다.
  • 접사와 관형사는 독립성 및 단어 내부 결합 여부가 다릅니다.
  • 접사와 어미는 새 단어 형성과 활용이라는 기준으로 구분합니다.
  • 접사에도 구체적인 어휘 의미가 있을 수 있습니다.
  • 사전 미등재만으로 접사 여부를 판단하지 않습니다.

12. 한눈에 정리 — 접사는 ‘붙는 위치’보다 ‘새 단어를 만드는 기능’이 핵심이다

항목접두사접미사
위치어근·단어 앞어근·단어 뒤
공통 기능새로운 단어 형성
대표 기능의미 추가·제한의미 추가, 때로 품사 변화
예풋고추, 맨손, 신도시덮개, 사랑하다, 바둑이
주의관형사와 구별어미와 구별, 모든 접미사가 품사를 바꾸는 것은 아님
접사를 찾을 때는 “어디에 붙었나?”보다 “무엇을 만들었나?”를 먼저 보아야 합니다.
접두사와 접미사는 위치가 다르지만 둘 다 단어 내부에서 새로운 어휘를 만드는 요소입니다.
