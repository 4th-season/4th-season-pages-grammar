어근이란 무엇인가 — 단어의 핵심 의미를 담당하는 부분

어근은 단어를 분석할 때 실질적 의미를 나타내는 중심 부분입니다. 다만 ‘뜻이 있는 부분’이라고만 외우면 어간·자립 형태소와 섞이기 쉽습니다. 어근은 무엇보다 단어 형성의 관점에서 읽어야 합니다.

1. 어근의 정확한 정의 — 단어의 실질적 의미를 나타내는 중심 부분

표준국어대사전은 어근을 “단어를 분석할 때, 실질적 의미를 나타내는 중심이 되는 부분”으로 풀이합니다. 예를 들어 ‘덮개’에서는 ‘덮-’, ‘어른스럽다’에서는 ‘어른’이 어근입니다.

덮- + -개 → 덮개　/　어른 + -스럽- + -다 → 어른스럽다

이 두 예에서 접사나 어미를 떼어 내고 남는다는 사실만이 중요한 것은 아닙니다. ‘덮-’과 ‘어른’이 각각 덮는 행위, 어른이라는 대상·속성이라는 어휘적 의미의 중심을 담당한다는 점이 핵심입니다.

어근 = 무조건 맨 앞부분이 아닙니다.
어근은 위치가 아니라 역할로 판단합니다. ‘풋고추’에서는 접두사 ‘풋-’ 뒤에 있는 ‘고추’가 어근입니다.

2. 왜 ‘실질적 의미의 중심’이라고 하는가

한 단어 안의 모든 형태소가 같은 무게로 의미를 담당하는 것은 아닙니다. 파생어에서 접사는 새 뜻을 보태거나 품사를 바꾸지만, 단어가 무엇에 관한 말인지 알려 주는 중심은 보통 어근이 맡습니다.

단어어근접사의미의 중심
덮개덮--개‘덮다’라는 동작
풋고추고추풋-‘고추’라는 대상
어른스럽다어른-스럽-‘어른’의 성질·특징
낮추다낮--추-‘낮다’의 상태

따라서 어근을 찾을 때는 “어느 조각이 가장 길게 남는가?”보다 “이 단어의 어휘적 내용을 무엇이 중심에서 떠받치는가?”를 묻는 편이 정확합니다.

3. 어근은 단어 형성의 개념이다 — 품사나 문장 성분과 다른 층위

어근은 명사·동사·조사 같은 품사 이름이 아니고, 주어·목적어 같은 문장 성분 이름도 아닙니다. 국립국어원은 어근과 접사를 단어 형성의 관점에서 구분하는 개념이라고 설명합니다.

단어 형성어근 · 접사
합성어 · 파생어
새 단어가 어떤 재료로 만들어졌는가를 봅니다.
활용어간 · 어미
먹다 · 먹고 · 먹으니
같은 용언이 문장에서 어떻게 형태를 바꾸는가를 봅니다.
‘조사도 뜻이 있으니 어근 아닌가?’라고 보면 층위가 섞입니다.
조사는 품사의 한 종류이고, 어근·접사는 조어론의 개념입니다. 서로 다른 질문에 대한 이름입니다.

4. 덮개·어른스럽다·풋고추 — 어근은 어디에 있는가

덮개

덮- (어근) + -개 (접미사) → 덮개

‘덮-’은 덮는 동작이라는 실질적 의미를 담당하고, ‘-개’는 도구나 사물의 이름을 만드는 접미사로 기능합니다.

어른스럽다

어른 (어근) + -스럽- (접미사) + -다 (어미)

‘어른’이 의미의 중심이고 ‘-스럽-’이 ‘그러한 성질이 있음’의 의미를 더해 형용사를 만듭니다. 마지막 ‘-다’는 단어 형성 요소가 아니라 활용에서 쓰이는 어미입니다.

풋고추

풋- (접두사) + 고추 (어근) → 풋고추

접사가 앞에 붙어도 어근이 사라지는 것은 아닙니다. ‘고추’가 대상의 중심 의미를 맡고, ‘풋-’이 ‘덜 익은’이라는 뜻을 보탭니다.

5. 어근은 하나만 있는가 — 합성어에는 둘 이상의 어근이 있을 수 있다

파생어는 보통 어근에 접사가 붙어 만들어지지만, 합성어는 둘 이상의 어근이 결합합니다. 따라서 “한 단어에는 어근이 하나”라고 외우면 합성어에서 바로 틀립니다.

강물강 + 물
두 요소가 모두 실질적 의미를 지닌 어근입니다.
힘들다힘 + 들-
단어 형성 관점에서는 두 부분을 각각 어근으로 볼 수 있습니다.

국립국어원의 설명처럼 ‘힘들다’의 경우 단어 형성에서는 ‘힘’과 ‘들-’이 각각 어근이고, 활용에서는 ‘힘들-’ 전체가 어간입니다. 이 예가 어근과 어간의 차이를 분명하게 보여 줍니다.

6. 강물과 눈높이 — 어근 수를 셀 때는 단어의 내부 단계를 본다

‘강물’은 비교적 단순합니다. ‘강’과 ‘물’이 바로 결합한 합성어이므로 두 어근을 쉽게 찾을 수 있습니다. 그러나 ‘눈높이’처럼 셋 이상의 형태소가 들어가면 한꺼번에 일렬로 나누는 것보다 직접 구성 요소를 단계적으로 분석해야 합니다.

눈높이 → 눈 + 높이　/　높이 → 높- + -이

2014년 국립국어원 표준 문법 개발 자료는 ‘눈높이’를 먼저 ‘눈’과 ‘높이’로 나누고, 다시 ‘높이’를 ‘높-’과 ‘-이’로 분석하는 방식을 제시합니다. 이때 ‘눈’과 ‘높-’은 실질 의미를 맡는 어근이고 ‘-이’는 명사를 만드는 접사입니다.

복잡한 단어는 ‘바로 붙어 있는 두 덩어리’를 먼저 찾습니다.
그다음 각 덩어리를 다시 분석해야 어근과 접사의 관계를 잘못 세지 않습니다.

7. 어근은 반드시 혼자 쓰일 수 있어야 하는가 — 아니다

어근과 자립 형태소·의존 형태소는 다른 기준입니다. 국립국어원은 어근이 자립 형태소일 때도 있고 의존 형태소일 때도 있다고 설명합니다.

예어근자립성설명
풋고추고추자립 가능‘고추’는 혼자 단어로도 쓰입니다.
덮개덮-의존‘덮-’만으로 문장에서 독립된 단어가 되지는 않습니다.
낮추다낮-의존용언의 어근은 흔히 다른 요소와 결합해 나타납니다.
‘혼자 쓸 수 있느냐’는 자립성의 문제이고, ‘단어의 실질적 의미 중심이냐’는 어근의 문제입니다.
두 분류를 한 기준처럼 섞지 않는 것이 중요합니다.

8. 어근과 어간은 어떻게 다른가 — 단어 형성과 활용을 나누어 본다

어근은 단어가 만들어지는 구조를 볼 때, 어간은 용언이 활용하는 구조를 볼 때 씁니다. 그래서 같은 형태가 두 이름을 동시에 가질 수도 있고, 서로 다른 범위를 가질 수도 있습니다.

단어단어 형성 관점활용 관점
먹다분석 견해에 따라 ‘먹-’을 어근으로 볼 수 있음먹- + -다 → 먹-은 어간
사랑하다사랑은 어근, -하-는 접사사랑하-는 어간, -다/-고/-니는 어미
힘들다힘 + 들- → 두 어근힘들- → 하나의 어간

따라서 “어근은 항상 어간보다 짧다”거나 “어간은 모두 어근이다”처럼 기계적으로 일반화하면 안 됩니다. 두 용어는 적용하는 분석 질문 자체가 다릅니다.

9. 단일어에서도 무조건 어근을 찾는가 — 학교 문법에서는 분석 목적을 먼저 본다

여기서 중요한 경계가 하나 있습니다. ‘덮다’처럼 파생어나 합성어가 아닌 단순한 용언을 볼 때, 국립국어원 온라인가나다는 일반적으로 단어 형성법에서는 어근·접사로 억지 분석하지 않고, 활용 차원에서 어간·어미로 기술할 수 있다고 안내합니다.

덮다 → 덮- (어간) + -다 (어미)
‘덮-’이 실질 의미의 중심이라는 점 때문에 어근 개념과 관련지을 수는 있지만, 실제 학교 문법 문제에서 단일어의 활용을 묻는다면 어간·어미 분석이 우선입니다.

즉 어근의 사전 정의와 특정 교과서의 분석 절차를 구분해야 합니다. 경계 사례에서는 교과서나 문제에서 채택한 분석 체계를 먼저 확인하는 것이 안전합니다.

10. 복잡한 단어를 단계별로 분석하기 — ‘짓밟히다’처럼 한 번에 자르지 않는다

셋 이상의 형태소로 이루어진 단어는 바로 모든 조각을 한 줄에 놓고 역할을 정하면 혼동하기 쉽습니다. 표준 문법 개발 자료는 직접 구성 요소를 단계적으로 분석하는 방식을 설명합니다.

짓밟히다 → 짓밟- + -히- + -다　/　짓밟- → 짓- + 밟-

여기에서 ‘밟-’은 중심 실질 의미를 가진 어근이고, ‘짓-’과 ‘-히-’는 단어 형성에 참여하는 접사입니다. 마지막 ‘-다’는 활용의 어미입니다. 한 단어 안에서도 단어 형성과 활용이라는 두 층위가 연속해서 나타날 수 있음을 보여 줍니다.

11. 실전에서 어근을 찾는 순서 — 뜻만 보지 말고 구조를 본다

1복합어인지 확인합성어나 파생어처럼 단어 형성 분석이 필요한 대상인지 봅니다.
2직접 구성 요소 나누기단어를 한꺼번에 잘게 쪼개지 말고 먼저 큰 두 덩어리로 나눕니다.
3실질 의미 중심 찾기대상·행위·상태 등 단어의 핵심 어휘 의미를 담당하는 부분을 찾습니다.
4접사·어간과 재확인나머지 요소가 새 단어를 만드는 접사인지, 활용의 어미인지 구별합니다.
  • 어근은 단어 형성의 관점에서 쓰는 개념입니다.
  • 어근은 실질적 의미의 중심 부분입니다.
  • 어근이 반드시 단어의 맨 앞에 오는 것은 아닙니다.
  • 합성어에는 어근이 둘 이상 있을 수 있습니다.
  • 어근은 자립 형태소일 수도, 의존 형태소일 수도 있습니다.
  • 어근과 어간은 같은 형태일 수도 있지만 개념은 다릅니다.
  • 복잡한 단어는 직접 구성 요소를 단계적으로 분석합니다.
  • 학교 문법의 경계 사례는 교과서의 분석 기준을 우선합니다.
