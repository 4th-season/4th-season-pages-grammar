단어의 내부 구조 — 어근·접사와 어간·어미를 구별하기

어근·접사와 어간·어미는 모두 단어 안의 부분을 가리키지만 같은 기준으로 나눈 이름이 아닙니다. 어근·접사는 새 단어가 어떻게 만들어졌는가를 보고, 어간·어미는 용언이 어떻게 활용하는가를 봅니다.

1. 네 용어가 헷갈리는 이유 — 모두 ‘단어 안의 부분’을 가리키기 때문이다

어근, 접사, 어간, 어미를 처음 배우면 네 용어가 한 줄에 놓인 같은 종류의 이름처럼 보입니다. 그러나 실제로는 분석 기준이 다릅니다. 어근과 접사는 단어가 만들어지는 구조를 설명하고, 어간과 어미는 동사·형용사 같은 활용어가 문장에서 형태를 바꾸는 구조를 설명합니다.

단어 형성의 관점 → 어근 + 접사　/　활용의 관점 → 어간 + 어미
먼저 “지금 무엇을 분석하는가?”를 물어야 합니다.
새 단어가 만들어지는 과정을 보는지, 이미 존재하는 용언이 ‘먹다·먹고·먹으니·먹었다’처럼 활용하는 과정을 보는지에 따라 같은 부분의 이름이 달라질 수 있습니다.

2. 두 개의 분석 질문 — 새 단어를 만드는가, 문장 속 형태를 바꾸는가

질문 A — 단어 형성이 단어는 어떤 의미 중심과 어떤 부가 요소가 결합해 만들어졌는가? 이 질문에서는 어근·접사를 찾습니다.
질문 B — 활용이 용언이 ‘-다, -고, -니, -었다’처럼 형태를 바꿀 때 무엇이 유지되고 무엇이 달라지는가? 이 질문에서는 어간·어미를 찾습니다.

따라서 형태가 하나뿐인 명사에도 어근과 접사는 분석할 수 있지만, 활용하지 않는 명사에는 일반적으로 어간과 어미라는 분석을 적용하지 않습니다. 반대로 동사·형용사는 활용하므로 어간과 어미를 나눌 수 있습니다.

3. 어근 — 단어의 중심 의미를 맡는 부분

표준국어대사전은 어근을 단어를 분석할 때 실질적 의미를 나타내는 중심 부분으로 설명합니다. 어근은 새 단어를 만들 때 의미의 중심축이 됩니다.

단어어근나머지 요소설명
덮개덮--개‘덮다’의 의미 중심에 명사를 만드는 접사가 붙음
풋사과사과풋-‘덜 익은’ 뜻을 더하는 접두사가 결합
먹히다먹--히-‘먹다’의 의미 중심에 피동 의미를 더하는 접미사가 결합
어근을 찾을 때는 “이 단어의 핵심 어휘적 의미가 어디에 남아 있는가?”를 봅니다.
접사가 떨어져도 기본적인 의미의 중심을 담당하는 부분이 어근입니다.

4. 접사 — 어근이나 단어에 붙어 새로운 단어를 만드는 부분

접사는 혼자 쓰이지 않고 어근이나 단어의 앞뒤에 붙어 새로운 단어를 구성합니다. 앞에 붙는 것은 접두사, 뒤에 붙는 것은 접미사입니다.

접두사풋- + 사과 → 풋사과
맨- + 손 → 맨손
새 단어의 의미 범위를 바꿉니다.
접미사덮- + -개 → 덮개
먹- + -히- → 먹히다
의미를 더하거나 품사·문법적 성격을 바꿀 수 있습니다.
접사는 단어 형성 요소입니다.
단순히 뒤에 붙는다는 이유로 어미와 같은 것으로 보면 안 됩니다. 접사가 붙으면 새 어휘 항목이 만들어지는 방향이고, 어미가 붙으면 같은 용언의 활용형이 만들어지는 방향입니다.

5. 어간 — 활용할 때 중심으로 남는 부분

어간은 활용어가 활용할 때 변하지 않는 부분입니다. ‘먹다, 먹고, 먹으니, 먹었다’를 비교하면 형태가 바뀌어도 먹-이 중심으로 남습니다. 이때 ‘먹-’은 어간입니다.

활용형어간어미
먹다먹--다
먹고먹--고
먹으니먹--으니
먹었다먹--었- + -다
어간은 ‘뜻의 중심’이라는 정의가 아니라 ‘활용할 때 남는 부분’이라는 정의입니다.
그래서 어떤 단어에서는 어근과 어간이 같고, 어떤 단어에서는 서로 다릅니다.

6. 어미 — 활용하면서 달라지는 부분

어미는 용언이나 서술격 조사가 활용할 때 변하는 부분입니다. ‘먹다, 먹고, 먹으니’의 -다, -고, -으니처럼 문장의 종결, 연결, 시간, 높임 등의 문법 기능을 나타냅니다.

-다문장을 끝맺는 종결 기능
-고앞뒤 내용을 이어 주는 연결 기능
-었-과거의 시간 의미를 나타내는 선어말 어미
-으니앞뒤 절을 연결하며 이유·배경 등의 관계를 나타냄

국립국어원 상담 사례는 접사와 어미를 구분할 때 접사는 새 단어를 만들지만, 어미는 용언에 두루 붙어 활용형을 만든다는 차이를 중요한 기준으로 설명합니다.

7. 어근과 어간이 같은 경우 — 먹다의 ‘먹-’

‘먹다’를 단어 형성의 관점에서 보면 ‘먹-’이 실질적 의미의 중심이므로 어근입니다. 같은 ‘먹다’를 활용의 관점에서 보면 ‘먹다·먹고·먹으니’에서 변하지 않는 부분이므로 어간이기도 합니다.

먹다 → 어근: 먹-　/　어간: 먹-　/　어미: -다

국립국어원도 ‘먹다’의 ‘먹-’은 분석 기준에 따라 어근이 될 수도 있고 어간이 될 수도 있다고 설명합니다. 이것은 두 용어가 중복되어 잘못 붙은 것이 아니라, 서로 다른 분석 질문에 대한 답이 우연히 같은 형태인 것입니다.

8. 어근과 어간이 다른 경우 — 먹히다의 ‘먹-’과 ‘먹히-’

피동사 ‘먹히다’는 네 용어의 차이를 가장 분명하게 보여 줍니다. 단어 형성 관점에서는 ‘먹-’에 피동 접미사 ‘-히-’가 붙어 새 동사 ‘먹히다’가 만들어집니다. 따라서 먹-은 어근, -히-는 접사입니다.

하지만 완성된 동사 ‘먹히다’가 활용할 때는 ‘먹히다·먹히고·먹히니’에서 먹히-가 변하지 않습니다. 이때 먹히-가 어간이고, 뒤의 ‘-다·-고·-니’가 어미입니다.

단어 형성: 먹- + -히- → 먹히다　/　활용: 먹히- + -다 → 먹히다
같은 단어를 두 번 다른 각도에서 분석할 수 있습니다.
어근·접사는 ‘어떻게 만들어졌나’를, 어간·어미는 ‘어떻게 활용하나’를 보여 줍니다.

9. 접사와 어미를 구별하는 핵심 — 새 단어인가, 같은 단어의 활용형인가

구분접사어미
분석 관점단어 형성활용
결합 대상어근이나 단어용언의 어간
결과새로운 단어같은 단어의 다른 활용형
예먹- + -히- → 먹히다먹히- + -고 → 먹히고
핵심 질문새 어휘를 만들었는가?문장 속 문법 기능을 바꾸었는가?
위치만으로 판단하면 틀립니다.
접미사도 뒤에 붙고 어미도 뒤에 붙습니다. ‘뒤에 붙는다’가 아니라 새 단어 형성인지 활용인지를 확인해야 합니다.

10. 덮개와 먹히다를 비교하면 구조가 선명해진다

덮개덮- + -개
어근 + 접미사로 이루어진 파생 명사입니다. 명사는 활용하지 않으므로 이 단어 자체를 어간·어미로 나누지 않습니다.
먹히다먹- + -히- + -다
단어 형성에서는 어근 + 접사, 활용에서는 어간 ‘먹히-’ + 어미 ‘-다’로 봅니다.

즉 형태소를 일렬로 잘라 놓은 뒤 모든 조각에 하나의 이름만 붙이려 하면 오류가 생깁니다. 같은 조각이라도 분석 층위에 따라 역할 이름이 달라질 수 있고, 어떤 용어는 특정 종류의 단어에만 적용됩니다.

11. 실전 판별 순서 — 네 용어를 한꺼번에 찾지 말고 질문을 분리한다

1품사 확인활용하는 용언인지, 활용하지 않는 체언·수식언인지 먼저 확인합니다.
2단어 형성 확인새 단어를 만드는 어근과 접사가 있는지 봅니다.
3활용 확인용언이라면 여러 활용형을 만들어 변하지 않는 어간과 변하는 어미를 찾습니다.
4두 결과 비교어근과 어간이 같은지, 접사 때문에 어간이 더 커졌는지 확인합니다.
  • 어근·접사는 단어 형성의 관점입니다.
  • 어간·어미는 활용의 관점입니다.
  • 명사 ‘덮개’는 어근·접사를 분석하지만 어간·어미로 나누지 않습니다.
  • ‘먹다’의 먹-은 어근이면서 어간일 수 있습니다.
  • ‘먹히다’에서는 어근 먹-보다 어간 먹히-가 더 큽니다.
  • 접미사와 어미는 위치가 아니라 기능으로 구분합니다.
  • 구체적인 경계 사례는 교과서와 사전의 분석 체계를 우선합니다.

12. 한눈에 정리 — 어근·접사와 어간·어미는 서로 다른 질문의 답이다

용어무엇을 보는가핵심 정의대표 예
어근단어 형성실질적 의미의 중심먹히다의 먹-
접사단어 형성어근·단어에 붙어 새 단어를 만드는 요소먹히다의 -히-
어간활용활용할 때 변하지 않는 부분먹히다·먹히고의 먹히-
어미활용활용할 때 변하는 부분-다, -고, -니
네 용어를 외우는 것보다 분석 관점을 먼저 고르는 것이 중요합니다.
새 단어의 제작 과정을 보면 어근·접사, 문장 속 활용을 보면 어간·어미입니다. 이 두 축을 분리하면 단어의 내부 구조가 훨씬 선명하게 보입니다.
