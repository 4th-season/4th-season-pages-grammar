실질 형태소와 형식 형태소 — 실질 의미를 갖는가를 기준으로 나누기

형태소는 모두 의미를 갖지만 그 의미의 성격은 다릅니다. 구체적인 대상·동작·상태를 직접 나타내면 실질 형태소, 실질 형태소에 붙어 관계나 문법 기능을 나타내면 형식 형태소로 나눕니다.

1. 실질 형태소와 형식 형태소 — ‘의미가 있느냐’가 아니라 ‘어떤 의미냐’가 기준이다

형태소는 뜻을 가진 가장 작은 말의 단위입니다. 따라서 실질 형태소뿐 아니라 형식 형태소도 의미를 가집니다. 차이는 의미의 종류입니다.

실질 형태소구체적인 대상, 동작, 상태, 성질처럼 어휘적인 내용을 직접 나타냅니다. 예: 하늘, 책, 먹-, 웃-, 오늘.
형식 형태소실질 형태소에 붙어 말과 말의 관계, 시제, 높임, 종결, 파생 같은 문법적 관계나 기능을 나타냅니다. 예: 조사, 어미, 접사.
형식 형태소도 의미가 있습니다.
‘-었-’은 과거, ‘-이/가’는 문장 성분의 관계, ‘-님’은 높임의 의미를 나타냅니다. 다만 그 의미가 사물이나 동작 자체를 가리키는 어휘적 의미가 아니라 문법적 관계 속에서 드러납니다.

2. 자립/의존과 실질/형식은 서로 다른 분류축이다

앞 글에서 본 자립 형태소와 의존 형태소는 혼자 설 수 있는가를 기준으로 나눕니다. 이번의 실질/형식 형태소는 어떤 성격의 의미를 갖는가를 기준으로 나눕니다. 두 분류는 같은 축이 아닙니다.

형태소자립/의존실질/형식이유
책자립실질혼자 설 수 있고 구체적인 대상을 나타냄
먹-의존실질어미가 필요하지만 ‘먹다’의 동작 의미를 지님
-었-의존형식과거라는 문법적 의미를 나타냄
-을/를의존형식목적어 관계를 표시함
‘의존 형태소 = 형식 형태소’는 틀립니다.
‘먹-’, ‘웃-’, ‘크-’ 같은 용언의 어간 형태소는 혼자 쓰일 수 없다는 점에서는 의존 형태소지만, 동작이나 상태를 직접 나타내므로 실질 형태소입니다.

3. 실질 형태소 — 대상·동작·상태를 직접 나타내는 최소 단위

표준국어대사전은 실질 형태소를 구체적인 대상이나 동작, 상태를 표시하는 형태소로 풀이합니다. 명사나 대명사, 수사처럼 자립하는 말뿐 아니라, 동사·형용사의 어근이나 단일 형태소 어간도 실질 형태소가 될 수 있습니다.

오늘+재미+있-+게임+하-

국립국어원은 “오늘도 재미있게 게임을 했다”에서 실질 형태소를 ‘오늘, 재미, 있-, 게임, 하-’로 제시합니다. 조사와 어미는 제외되지만, ‘있-’, ‘하-’처럼 혼자 쓰이지 못하는 어간 형태소는 포함됩니다.

4. 형식 형태소 — 조사·어미·접사가 대표적이다

형식 형태소는 실질 형태소에 붙어 관계나 기능을 나타냅니다. 학교 문법에서 가장 대표적인 유형은 조사, 어미, 접사입니다.

유형예기능
조사-이/가, -을/를, -도, -까지체언과 다른 성분의 관계 또는 보조적 의미 표시
어미-었-, -시-, -다, -고시제·높임·종결·연결 등 문법 기능 표시
접사민-, 덧-, -님, -히-, -이새 단어를 만들거나 뜻을 더하는 파생 기능
접사가 의미를 가진다고 실질 형태소가 되는 것은 아닙니다.
예를 들어 ‘-님’은 높임, ‘민-’은 아무것도 덧붙지 않은 상태, ‘덧-’은 거듭 더한다는 뜻을 더하지만, 이런 의미는 결합한 말과의 관계 속에서 기능하므로 학교 문법에서는 일반적으로 형식 형태소로 분류합니다.

5. ‘용언의 어간은 실질 형태소’라는 말을 그대로 외우면 틀릴 수 있다

학교 문법에서 단순한 예를 배울 때는 ‘먹-’, ‘웃-’, ‘놀-’ 같은 어간을 실질 형태소라고 합니다. 하지만 어간이 언제나 형태소 하나인 것은 아닙니다.

새하얗- → 새- + 하얗-

국립국어원은 ‘새하얗-’ 전체를 실질 형태소 하나로 볼 수 없다고 설명합니다. ‘새-’와 ‘하얗-’으로 더 나눌 수 있기 때문입니다. 실질 형태소도 먼저 형태소 단위여야 하므로, 복합 어간은 내부 형태소를 다시 분석해야 합니다.

“모든 어간은 실질 형태소”라고 쓰지 마십시오.
어간 내부에 접사나 다른 형태소가 포함될 수 있습니다. 먼저 형태소 경계를 찾고, 그 각각을 실질/형식으로 분류해야 합니다.

6. 접사는 왜 형식 형태소인가 — ‘뜻이 없다’가 아니다

접사는 새 단어를 만드는 중요한 의미 기능을 가집니다. 그렇다면 왜 형식 형태소일까요? 핵심은 의미의 독립성이 아니라 의미가 나타나는 방식입니다.

국립국어원은 보조사와 접사도 의미를 가지지만, 실질 형태소처럼 대상을 직접 가리키는 어휘적 의미라기보다 결합하는 말과의 관계 속에서 나타나는 의미로 보아 형식 형태소로 보는 것이 일반적이라고 설명합니다.

따님따-?가 아니라 ‘딸’의 변형과 접미사 ‘-님’이 결합하며, ‘-님’은 높임을 더하는 형식 형태소입니다.
덧버선접두사 ‘덧-’은 ‘거듭 더함’의 뜻을 더하지만 혼자 대상이나 동작을 가리키는 실질 형태소가 아니라 파생 기능을 하는 형식 형태소입니다.

7. 의존 명사는 실질 형태소다 — ‘의존’이라는 이름에 속지 말 것

‘것’, ‘수’, ‘바’ 같은 의존 명사는 앞말의 관형어 수식을 필요로 하므로 통사적으로 의존적입니다. 하지만 형태론적 분류에서는 명사의 하나이며, 일반적으로 자립 형태소이자 실질 형태소로 봅니다.

이름보다 분류 기준을 보십시오.
‘의존 명사’의 ‘의존’은 품사 체계에서의 통사적 의존성을 말합니다. ‘의존 형태소’의 ‘의존’은 형태적으로 혼자 쓰일 수 없는지를 묻습니다. 서로 같은 말처럼 보여도 기준이 다릅니다.

따라서 “의존 명사니까 의존 형태소”, “혼자 뜻이 약하니까 형식 형태소”라고 자동 판정하면 안 됩니다.

8. 문장 분석 — ‘오늘도 재미있게 게임을 했다’

형태소를 실질/형식으로 나눌 때는 먼저 문장을 최소 의미 단위로 쪼갠 뒤 각 형태소의 의미 성격을 봅니다.

형태소분류근거
오늘실질시간 대상을 직접 나타냄
-도형식보조사로 관계·보조 의미 표시
재미실질구체적인 개념을 나타냄
있-실질상태를 직접 나타냄
-게형식부사형 전성 기능을 하는 어미
게임실질대상을 나타냄
-을형식목적격 관계 표시
하-실질동작을 직접 나타냄
-았- / -다형식과거·종결 기능 표시

9. 판별 순서 — 먼저 형태소를 찾고, 그 다음 의미 성격을 본다

1형태소 경계 찾기더 나누면 의미나 기능이 사라지는 최소 단위까지 나눕니다.
2대상·동작·상태인가직접적인 어휘 의미를 나타내면 실질 형태소입니다.
3관계·문법 기능인가조사·어미·접사처럼 관계나 기능을 나타내면 형식 형태소입니다.
4다른 분류축과 분리자립/의존 여부와 섞지 않고 따로 판정합니다.
  • 형식 형태소도 의미를 가진다는 사실을 기억합니다.
  • 의존 형태소라고 해서 모두 형식 형태소인 것은 아닙니다.
  • 어간 전체가 형태소 하나인지 먼저 확인합니다.
  • 접사의 의미가 구체적으로 느껴져도 학교 문법에서는 일반적으로 형식 형태소로 봅니다.
  • 의존 명사는 일반적으로 자립 형태소이자 실질 형태소로 분류합니다.

10. 한눈에 정리 — 두 분류축을 교차해 보면 선명해진다

조합대표 예설명
자립 + 실질책, 오늘, 사람, 것혼자 설 수 있고 어휘적 의미를 가짐
의존 + 실질먹-, 웃-, 많-어미에 기대지만 동작·상태 의미를 직접 가짐
의존 + 형식-이/가, -었-, -다, 민-, -님다른 말에 붙어 문법 관계나 파생 기능을 나타냄
실질/형식 형태소의 핵심은 “의미가 있느냐”가 아니라 “그 의미가 대상·동작·상태를 직접 가리키는가, 아니면 관계·문법 기능을 나타내는가”입니다.
먼저 형태소 경계를 찾고, 그 다음 의미 성격을 판정하면 자립/의존 분류와 섞이지 않습니다.
