단일어란 무엇인가 — 하나의 어근으로 이루어진 단어

단일어는 단어 형성의 관점에서 하나의 어근으로 이루어진 단어입니다. 글자가 짧은지, 형태소가 몇 개인지만 세어서는 정확히 판별할 수 없습니다. 특히 용언의 어미는 단어 형성 판별에서 제외해야 합니다.

1. 단일어의 정확한 뜻 — 단어 형성에서 하나의 어근으로 이루어진 단어

단어를 형성 방식에 따라 나누면 크게 단일어와 복합어로 볼 수 있습니다. 단일어는 하나의 실질적 중심, 곧 하나의 어근만으로 이루어진 단어입니다. 반대로 둘 이상의 어근이 결합하거나 어근에 접사가 붙어 새 단어가 만들어지면 복합어가 됩니다.

하나의 어근 → 단일어　/　어근 + 어근 또는 어근 + 접사 → 복합어

따라서 단일어를 판별할 때는 “몇 글자인가?”가 아니라 “단어 형성에 참여한 어근과 접사가 몇 개인가?”를 물어야 합니다.

핵심 기준
단일어는 하나의 어근으로 이루어진 단어입니다. 활용할 때 붙는 어미는 단어 형성 요소로 세지 않습니다.

2. 산과 하늘은 왜 단일어인가 — 더 붙은 조어 요소가 없다

‘산’, ‘하늘’, ‘집’, ‘꽃’ 같은 말은 단어 내부에서 접사를 떼어 내거나 둘 이상의 어근으로 나눌 수 없습니다. 각각 하나의 실질적 의미 중심으로 이루어져 있으므로 단일어로 봅니다.

단어단어 형성 분석판정
산산단일어
하늘하늘단일어
집집단일어
꽃꽃단일어

여기서 중요한 것은 음절 수가 아닙니다. ‘산’은 한 음절이고 ‘하늘’은 두 음절이지만 둘 다 단일어입니다. 음절 수와 어근 수는 서로 다른 기준입니다.

3. 먹다와 푸르다는 왜 단일어인가 — 어미 ‘-다’는 조어 요소가 아니다

학생들이 가장 자주 헷갈리는 지점은 용언입니다. ‘먹다’는 ‘먹- + -다’, ‘푸르다’는 ‘푸르- + -다’로 형태소를 나눌 수 있습니다. 그렇다면 형태소가 둘이니 복합어일까요? 일반적인 학교 문법의 단어 형성 판별에서는 그렇지 않습니다.

먹- + -다 → 먹다 = 단일어
푸르- + -다 → 푸르다 = 단일어

국립국어원 온라인가나다는 단일어와 복합어를 구분할 때 일반적으로 어미는 고려하지 않는다고 설명합니다. ‘-다’는 새 단어를 만드는 접사가 아니라, 용언이 활용할 때 쓰이는 어미이기 때문입니다.

형태소가 둘이라고 복합어가 되는 것은 아닙니다.
‘먹다’의 ‘-다’는 어미입니다. 단어 형성 여부를 판단할 때는 어근·접사와 어근의 결합을 봅니다.

4. 형태소 수만 세면 왜 틀리는가 — 형태소 분석과 단어 형성 분석은 목적이 다르다

형태소 분석은 한 단어를 뜻과 기능을 가진 최소 단위로 나눕니다. 반면 단어 형성 분석은 그 단어가 어떤 조어 요소의 결합으로 만들어졌는가를 봅니다. 그래서 같은 단어를 두고 분석 단위가 달라질 수 있습니다.

형태소 분석먹다 → 먹- + -다
실질 형태소와 형식 형태소를 모두 확인합니다.
단어 형성 분석먹다 → 하나의 어근을 가진 단일어
활용 어미는 조어 판별에서 제외합니다.

이 차이를 모르면 “먹다는 형태소가 둘이므로 복합어”라는 오답이 나옵니다. 문법에서는 같은 재료를 보더라도 어떤 질문을 하고 있는지가 중요합니다.

5. 풋사과와 낮추다는 왜 단일어가 아닌가 — 접사가 단어 형성에 참여한다

‘풋사과’는 ‘풋- + 사과’, ‘낮추다’는 ‘낮- + -추- + -다’로 분석할 수 있습니다. 두 단어에는 각각 접두사와 접미사가 단어 형성에 참여합니다.

단어형성 구조판정
풋사과풋- + 사과파생어
낮추다낮- + -추- + -다파생어
밤낮밤 + 낮합성어
먹다먹- + -다단일어

국립국어원은 ‘낮추다’를 어근 ‘낮-’에 사동 접미사 ‘-추-’가 붙은 파생어로 설명합니다. 여기서 ‘-다’는 어미이므로 파생 여부를 결정하는 핵심 요소가 아닙니다.

6. ‘하나의 어근’이라는 기준 — 단일어를 가장 안전하게 판별하는 방법

단일어를 “더 이상 나눌 수 없는 단어”라고만 외우면 ‘먹다’ 같은 용언에서 문제가 생깁니다. ‘먹다’는 형태소 차원에서는 나눌 수 있기 때문입니다. 더 정확한 표현은 단어 형성의 관점에서 하나의 어근으로 이루어진 단어입니다.

판별 질문을 바꾸세요.
“형태소가 몇 개인가?”보다 “새 단어를 만드는 접사가 붙었는가?”, “둘 이상의 어근이 결합했는가?”를 먼저 묻습니다. 둘 다 아니라면 단일어일 가능성이 높습니다.

7. 단일어와 ‘단순한 단어’는 다르다 — 길이와 난이도는 기준이 아니다

단일어의 ‘단일’은 뜻이 쉽다는 의미도, 글자가 짧다는 의미도 아닙니다. 일상에서 자주 쓰는 짧은 말도 복합어일 수 있고, 음절이 길어 보여도 하나의 어근으로 분석되는 말은 단일어일 수 있습니다.

짧아도 복합어밤낮 → 밤 + 낮
두 어근이 결합한 합성어입니다.
길어도 단일어 가능단어의 길이만으로는 판단하지 않습니다.
조어 구조를 확인해야 합니다.

시험에서 글자 수나 음절 수는 단일어 판별 기준이 아닙니다. 문법 단위와 문자 단위를 섞지 않는 것이 중요합니다.

8. 한자어는 어떻게 보아야 하나 — 글자 하나를 바로 어근 하나로 세지 않는다

한자어는 겉으로 여러 한자가 결합해 보이기 때문에 단일어·복합어 판정에서 특히 조심해야 합니다. 한자 하나하나를 자동으로 독립 어근으로 세면 실제 국어의 조어 구조와 어긋날 수 있습니다.

국립국어원 온라인가나다도 단일어·복합어 분석은 학자에 따라 견해차가 있을 수 있으며, 구체적인 어휘의 분석은 사전의 접사 정보나 교과서의 체계를 참고하는 것이 좋다고 안내합니다.

한자 수 = 어근 수가 아닙니다.
실제 국어에서 그 요소가 조어 단위로 분석되는지, 사전과 교과서가 어떻게 처리하는지를 확인해야 합니다.

9. 어근과 어간을 섞지 않는 법 — 먹다는 하나의 단일어이면서 먹-은 어간이다

‘먹다’에서 ‘먹-’은 활용할 때 형태가 유지되는 부분이므로 어간입니다. 동시에 단어의 실질 의미 중심이라는 관점에서는 어근과 관련지어 설명할 수 있습니다. 다만 어근은 단어 형성, 어간은 활용이라는 서로 다른 분석 관점의 개념입니다.

단어 형성: 먹다 = 단일어
활용: 먹- (어간) + -다 (어미)

따라서 단일어 판별 문제에서 어간·어미 분석을 그대로 가져와 형태소 수를 세면 안 됩니다. 먼저 문제의 층위를 정해야 합니다.

10. 경계 사례에서는 무엇을 따라야 하나 — 교과서와 사전의 분석 체계를 확인한다

모든 단어의 조어 구조가 하나의 절대적인 분석만을 갖는 것은 아닙니다. 어근과 접사의 경계를 어디까지 인정할지, 오래된 결합을 현재도 생산적인 단어 형성으로 볼지에 따라 견해가 달라지는 예가 있습니다.

국립국어원도 이러한 문제에서 견해차가 있을 수 있다고 반복해 안내합니다. 학교 문법 학습에서는 교과서에서 채택한 분석과 표준국어대사전의 접사·단어 정보를 우선하는 것이 안전합니다.

경계 사례를 억지로 일반화하지 않습니다.
명확한 단일어·파생어·합성어부터 판별 원리를 익힌 뒤, 분석이 갈릴 수 있는 말은 사전과 교과서 기준으로 따로 처리합니다.

11. 실전에서 단일어를 판별하는 네 단계

1활용 어미 제외용언이면 먼저 ‘-다’, ‘-고’, ‘-니’ 같은 어미를 단어 형성 판별에서 제외합니다.
2접사 확인접두사나 접미사가 새 단어를 만드는 데 참여했는지 봅니다.
3어근 수 확인둘 이상의 실질적 어근이 결합했는지 확인합니다.
4최종 판정접사가 없고 어근이 하나라면 단일어로 판정합니다.

12. 자주 틀리는 판단 — 형태소, 음절, 어미를 구분한다

  • ‘하늘’은 두 음절이지만 하나의 어근으로 이루어진 단일어입니다.
  • ‘먹다’는 먹-과 -다 두 형태소로 나뉘지만 단어 형성에서는 단일어입니다.
  • ‘낮추다’는 -추-가 파생 접미사이므로 단일어가 아니라 파생어입니다.
  • ‘밤낮’은 짧지만 밤과 낮 두 어근이 결합한 합성어입니다.
  • 접사가 붙어도 품사가 반드시 바뀌는 것은 아니지만 파생어는 됩니다.
  • 어미는 활용 요소이므로 단일어·복합어 판별에서 일반적으로 세지 않습니다.
  • 한자 수와 어근 수를 동일하게 취급하지 않습니다.
  • 경계 사례는 교과서와 사전의 분석을 확인합니다.

13. 한눈에 정리 — 단일어는 ‘하나의 어근’이 핵심이다

새 단어를 만드는 접사가 있는지, 둘 이상의 어근이 결합했는지를 보고 하나의 어근이 남는지를 확인하면 됩니다.
