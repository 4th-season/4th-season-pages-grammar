형태소 분석 — 단어를 최소 의미 단위로 나누는 법

형태소 분석은 겉으로 보이는 글자를 잘라 내는 작업이 아닙니다. 말 속에 숨어 있는 최소 의미 단위를 복원하고, 각 단위가 어떤 뜻과 문법 기능을 담당하는지 확인하는 과정입니다. 특히 축약된 활용형과 접사가 붙은 단어에서는 표면형보다 기본 구조를 먼저 찾아야 합니다.

1. 형태소 분석 — 말을 최소 의미 단위까지 내려가 보는 일

형태소는 뜻을 가진 가장 작은 말의 단위입니다. 따라서 형태소 분석은 한 단어 또는 어절을 보고 더 나누었을 때 각각의 조각에 의미나 문법 기능이 남는 지점까지 내려가는 작업입니다.

형태소 분석 = 표면형 확인 → 기본 구조 복원 → 최소 의미 단위 분리 → 각 형태소의 기능 판정
형태소 분석의 핵심은 ‘글자 자르기’가 아니라 ‘구조 복원’입니다.
눈에 보이는 음절 경계와 형태소 경계는 자주 어긋납니다. ‘했어요’의 ‘했’은 한 음절이지만 분석하면 ‘하-+-였-’로 나뉘고, ‘먹히다’의 ‘먹히-’는 하나의 어간이지만 ‘먹-+-히-’로 더 나뉩니다.

2. 첫 단계 — 지금 보이는 형태보다 기본형을 먼저 찾는다

활용하거나 축약된 말은 겉모양만 보고 자르면 틀리기 쉽습니다. 먼저 사전의 기본형과 활용 관계를 확인한 뒤 어떤 어미·접사·조사가 결합했는지 복원해야 합니다.

표면형복원한 구조분석 포인트
할하- + -ㄹ동사 어간 + 관형사형 어미
했다하- + -였- + -다‘하였-’이 ‘했-’으로 준 형태
줬다주- + -었- + -다‘주었-’의 축약형을 복원
뭘뭐 + ㄹ축약된 조사 결합형을 복원해 분석
분석 전에 “본말은 무엇인가?”를 먼저 묻습니다.
국립국어원도 ‘했어요’를 ‘하-+-였-+-어+요’처럼 분석하고, ‘할’을 ‘하-+-ㄹ’로 분석합니다. 즉 현재 표기만 잘게 나누는 것이 아니라 활용 전 구조를 되찾는 과정이 필요합니다.

3. 먹히다 — 어간 전체를 하나의 형태소로 보면 안 된다

‘먹히다’는 형태소 분석의 대표적인 기준 사례입니다. 활용 관점에서는 ‘먹히-’가 어간이지만, 형태소 분석에서는 더 작은 의미 단위로 나뉩니다.

먹히다→먹-+-히-+-다
형태소역할분류
먹-‘음식을 먹다’라는 핵심 의미어근 · 실질 형태소 · 의존 형태소
-히-피동의 뜻을 더함접사 · 형식 형태소 · 의존 형태소
-다용언을 기본형으로 끝맺음어미 · 형식 형태소 · 의존 형태소
어간과 형태소를 같은 단위로 생각하지 마십시오.
‘먹히-’는 활용할 때 변하지 않는 어간이지만 그 내부에는 어근 ‘먹-’과 피동 접사 ‘-히-’라는 두 형태소가 있습니다. 분석 층위가 다릅니다.

4. 활용형 — 어간 뒤의 어미를 기능별로 분리한다

활용형에서는 어간을 먼저 찾고, 그 뒤에 붙은 선어말 어미와 어말 어미를 구분합니다. ‘있었어요’는 국립국어원의 설명에 따르면 있- + -었- + -어 + 요로 분석할 수 있습니다.

있-용언의 어간으로 핵심 상태 의미를 담당합니다.
-었-과거 시제를 나타내는 선어말 어미입니다.
-어뒤의 ‘요’와 결합하는 어미입니다.
요상대 높임의 기능을 더하는 요소입니다.

‘아끼셨다’도 같은 방식으로 표면의 ‘셨’을 하나로 두지 않고, 아끼- + -시- + -었- + -다처럼 높임과 시제 기능을 분리해 분석합니다.

5. 축약형 — 소리와 표기가 줄어도 형태소가 사라진 것은 아니다

한국어의 활용에서는 여러 형태가 합쳐져 짧아지는 일이 많습니다. 하지만 축약은 표면형의 변화이지 반드시 형태소 구조 자체가 사라졌다는 뜻은 아닙니다.

표면형형태소 분석주의점
했어요하- / -였- / -어 / 요‘했-’을 하나의 형태소로 세지 않음
줘주- / -어‘주어’가 줄어든 형태를 복원
할하- / -ㄹ‘할’ 한 음절 안에 어간과 어미가 결합
뭘뭐 / ㄹ표면 음절 수와 형태소 수가 다를 수 있음
표면 음절 수 ≠ 형태소 수
한 음절 안에 둘 이상의 형태소가 합쳐져 나타날 수 있고, 반대로 여러 음절이 형태소 하나를 이루기도 합니다. 형태소 분석은 소리 단위가 아니라 의미·문법 기능 단위의 분석입니다.

6. 조사·어미·접사 — 붙어 있다고 모두 같은 종류는 아니다

형태소 분석에서 가장 많이 헷갈리는 부분은 ‘붙어서 쓰이는 요소’를 전부 같은 것으로 보는 것입니다. 조사·어미·접사는 모두 의존적인 성격이 있지만 기능과 결합 대상이 다릅니다.

종류무엇에 붙는가기능예
조사주로 체언문법 관계나 의미 관계 표시집-에, 사람-이
어미용언 어간시제·높임·종결·연결 등 표시먹-었-다
접사어근새 단어를 만들거나 뜻을 더함먹-히-다, 맨-손
‘에서는’를 무조건 ‘에 + 서 + 는’으로 나누면 안 됩니다.
표준국어대사전은 조사 ‘에서’를 ‘에’와 ‘서’의 결합이 아닌 하나의 단일 조사로 봅니다. 형태소 분석에서는 실제 사전의 단위 판정도 확인해야 합니다.

7. 복합어 — 직접 구성 성분과 형태소 분석을 구분한다

복합어는 먼저 큰 구성 덩어리를 보는 직접 구성 성분 분석과, 최소 의미 단위까지 내려가는 형태소 분석을 나누어야 합니다.

달맞이의 직접 구성 성분달 / 맞이
달맞이의 형태소달 / 맞- / -이

마찬가지로 파생어는 접사가 붙었다는 사실을 놓치지 않아야 합니다. ‘돌아온’은 국립국어원의 예처럼 돌- + -아 + 오- + -ㄴ, ‘물어봤다’는 묻- + -어 + 보- + -았- + -다로 더 세분할 수 있습니다.

8. 형태소 수 세기 — 먼저 분석하고, 마지막에 센다

시험에서 “형태소가 몇 개인가”를 먼저 계산하려 하면 축약형이나 복합 어간에서 실수하기 쉽습니다. 형태소 수는 분석의 결과이지 출발점이 아닙니다.

1표면형 확인현재 단어나 어절을 그대로 적습니다.
2기본 구조 복원활용·축약 전 형태를 되찾습니다.
3최소 단위 분리어근·접사·조사·어미를 나눕니다.
4마지막에 개수 계산남은 최소 단위의 수를 셉니다.
“몇 개?”보다 “왜 여기서 나누는가?”가 먼저입니다.
각 경계마다 의미나 문법 기능이 달라지는지를 설명할 수 있어야 안정적인 형태소 분석이 됩니다.

9. 형태소 분석은 모든 단어에서 하나의 절대 답이 있는가

그렇지 않습니다. 국립국어원도 형태소 분석은 학자나 문법 체계에 따라 견해 차이가 있을 수 있다고 반복해서 안내합니다. 특히 비자립적 어근, 굳어진 표현, 축약형, 역사적 구조에서는 분석이 달라질 수 있습니다.

예를 들어 ‘착하다’와 ‘위하다’는 표준국어대사전에서 각각 ‘착’, ‘위’를 어근으로 제시하므로 착 / -하- / -다, 위 / -하- / -다처럼 분석할 수 있지만, 학교 문제에서는 교과서가 채택한 분석 기준을 따라야 합니다.

학교 문법에서는 교과서 체계가 최종 기준입니다.
사전과 온라인가나다는 구조를 확인하는 좋은 근거지만, 평가 문항은 해당 교육과정과 교과서의 분석 체계를 전제로 합니다. 견해 차이가 있는 사례를 절대 규칙처럼 외우지 않는 것이 중요합니다.

10. 실전 형태소 분석 순서

  • 먼저 단어인지 어절인지 확인하고, 필요하면 띄어쓰기부터 바로잡습니다.
  • 용언이면 기본형을 찾아 어간과 어미의 경계를 확인합니다.
  • 축약형이면 본말을 복원합니다. ‘했-’은 ‘하였-’, ‘줘’는 ‘주어’를 떠올립니다.
  • 어간 내부에 접사가 있는지 확인합니다. ‘먹히-’는 ‘먹-/-히-’로 나뉩니다.
  • 체언 뒤에는 조사가 붙었는지 확인합니다. 단일 조사인지 복합 구성인지 사전을 참고합니다.
  • 복합어는 직접 구성 성분과 형태소 분석을 구분합니다.
  • 각 단위가 더 나뉘어도 의미나 문법 기능이 남는지 확인합니다.
  • 마지막에 형태소의 종류와 개수를 셉니다.

11. 한눈에 정리 — 형태소 분석은 ‘숨은 구조’를 복원하는 일

분석 대상형태소 분석핵심 포인트
먹히다먹- / -히- / -다복합 어간 내부의 접사를 분리
했어요하- / -였- / -어 / 요축약 전 형태 복원
할 것이다하- / -ㄹ / 것 / 이- / -다의존 명사와 서술격 조사까지 구분
달맞이달 / 맞- / -이직접 구성 성분보다 더 작은 최소 단위까지 분석
물어봤다묻- / -어 / 보- / -았- / -다보조 용언과 시제 어미를 분리
형태소 분석은 글자를 잘게 자르는 기술이 아니라, 단어가 만들어지고 활용되는 문법 구조를 역으로 복원하는 작업입니다.
기본형을 찾고, 축약을 풀고, 어근·접사·조사·어미의 기능을 확인한 뒤 최소 의미 단위까지 내려가면 대부분의 문제를 안정적으로 분석할 수 있습니다.
