단어 형성이란 무엇인가 — 단일어·합성어·파생어의 전체 체계

단어 형성은 단어가 어떤 어근과 접사의 결합으로 만들어졌는지를 보는 일입니다. 핵심은 글자 수가 아니라 구조입니다. 하나의 어근이면 단일어, 둘 이상의 어근이 결합하면 합성어, 어근에 접사가 붙으면 파생어로 읽는 것이 기본 지도입니다.

1. 단어 형성에서 보는 것 — 완성된 단어 안의 ‘조어 구조’를 본다

단어를 형태소로 나누는 일과 단어가 어떻게 형성되었는지를 분류하는 일은 서로 연결되어 있지만 완전히 같은 작업은 아닙니다. 형태소 분석은 단어 안에 어떤 최소 단위가 있는지 살피는 작업이고, 단어 형성은 그중 어근과 접사가 어떤 관계로 결합했는지를 중심으로 봅니다.

단어 형성의 기본 질문 = 어근이 몇 개인가? + 접사가 있는가?

이 질문을 따라가면 단어는 크게 단일어와 복합어로 나뉘고, 복합어는 다시 합성어와 파생어로 나뉩니다.

형성 구조를 보는 관점
단어의 글자 수나 음절 수가 아니라, 단어 내부에서 의미의 중심인 어근이 몇 개이며 새 단어를 만드는 접사가 결합했는지를 봅니다.

2. 전체 지도 — 단일어와 복합어, 그리고 합성어·파생어

큰 분류형성 구조하위 유형대표 예
단일어하나의 어근—산, 하늘, 먹다
복합어둘 이상의 어근 결합합성어밤낮, 집안, 공부방
어근에 접사 결합파생어덧신, 먹이, 풋고추

표준국어대사전의 설명을 따르면 단일어는 하나의 실질 형태소로 된 말이고, 복합어는 하나의 실질 형태소에 접사가 붙거나 둘 이상의 실질 형태소가 결합한 말입니다. 학교 문법에서는 이를 어근과 접사의 관점으로 바꾸어 설명하면 구조가 더 선명해집니다.

복합어 = 합성어 + 파생어
‘복합어’는 합성어만을 뜻하지 않습니다. 접사가 붙어 만들어진 파생어도 복합어에 포함됩니다.

3. 단일어 — ‘짧은 단어’가 아니라 하나의 어근으로 이루어진 단어

단일어는 단어 형성의 관점에서 더 이상 어근과 접사의 결합으로 나누지 않는 단어입니다. ‘산’, ‘하늘’, ‘밥’처럼 명사는 물론이고 ‘먹다’, ‘가다’, ‘푸르다’ 같은 용언도 단일어가 될 수 있습니다.

산하나의 어근으로 이루어진 명사입니다.
먹다형태소 분석에서는 먹- + -다로 나뉘지만 단어 형성 분류에서는 어미 -다를 세지 않으므로 단일어입니다.

따라서 단일어를 “형태소가 하나뿐인 단어”라고 기계적으로 외우면 용언에서 혼란이 생길 수 있습니다. 조어 구조에서 어미를 제외하고 하나의 어근만 남는가를 보는 편이 안전합니다.

4. 복합어 — 단어 내부에 형성 요소가 둘 이상 결합한 경우

복합어는 하나의 실질 형태소에 접사가 붙거나 둘 이상의 실질 형태소가 결합한 단어입니다. 이 두 형성 방식이 각각 파생과 합성입니다.

합성어어근 + 어근
예: 밤 + 낮 → 밤낮
집 + 안 → 집안
파생어어근 + 접사 또는 접사 + 어근
예: 덧- + 신 → 덧신
먹- + -이 → 먹이

즉 복합어인지 먼저 판단한 뒤, 그 결합 요소가 모두 어근인지 접사가 포함되어 있는지를 확인하면 합성어와 파생어를 나눌 수 있습니다.

5. 합성어 — 둘 이상의 어근이 결합해 하나의 새 단어가 된다

합성어의 핵심은 둘 이상의 어근입니다. ‘밤낮’은 ‘밤’과 ‘낮’, ‘공부방’은 ‘공부’와 ‘방’처럼 각각 의미의 중심이 되는 요소가 결합해 하나의 단어를 이룹니다.

단어구조판정핵심 이유
밤낮밤 + 낮합성어두 어근 결합
집안집 + 안합성어두 어근 결합
공부방공부 + 방합성어두 어근 결합

합성어 내부의 결합 방식은 뒤에서 통사적 합성어와 비통사적 합성어로 더 세분할 수 있지만, 이 글에서는 먼저 어근+어근이면 합성어라는 전체 지도를 잡는 데 집중합니다.

6. 파생어 — 접사가 들어오면 새 단어의 의미나 품사가 달라질 수 있다

파생어는 어근에 접사가 결합해 만들어진 단어입니다. 접두사는 어근 앞에, 접미사는 어근 뒤에 결합합니다.

덧- + 신 → 덧신‘덧-’이 앞에 붙은 접두 파생어입니다.
먹- + -이 → 먹이‘-이’가 뒤에 붙은 접미 파생어입니다.

접사는 새 단어를 만드는 요소이므로, 파생어에서는 결합 전후의 의미가 달라지거나 경우에 따라 품사가 바뀔 수 있습니다. 그러나 모든 접미사가 반드시 품사를 바꾸는 것은 아닙니다.

파생어 판별의 핵심
앞이나 뒤에 붙은 조각이 단순히 문장 관계나 활용을 나타내는 것이 아니라, 새 어휘를 만드는 접사인지 확인합니다.

7. 어미는 왜 세지 않는가 — 활용과 단어 형성은 다른 층위다

‘먹다’는 먹- + -다로 형태소가 둘입니다. 그렇다면 복합어일까요? 일반적인 학교 문법의 단어 형성 분류에서는 그렇지 않습니다. 국립국어원도 단일어와 복합어를 나눌 때 어미는 조어적 기준으로 고려하지 않는다고 설명합니다.

먹다 = 먹-(어근·어간) + -다(어미) → 단어 형성 분류에서는 단일어

어미는 새 단어를 만드는 접사가 아니라 같은 용언을 문장 속에서 활용시키는 요소입니다. 따라서 ‘먹다·먹고·먹으면·먹었다’는 활용형이 달라도 같은 단어의 활용으로 봅니다.

형태소가 둘 이상이라고 곧바로 복합어는 아닙니다.
그중 하나가 어미라면 단어 형성의 재료로 세지 않습니다.

8. 형태소 수만 세면 틀리는 이유 — ‘무슨 형태소인가’를 먼저 봐야 한다

형태소 분석과 단어 형성 분류를 혼동하면 “형태소가 두 개이니 복합어” 같은 오답이 생깁니다. 중요한 것은 개수가 아니라 종류와 기능입니다.

단어형태소 분석단어 형성 판정이유
먹다먹- + -다단일어-다는 어미
덧신덧- + 신파생어덧-은 접두사
밤낮밤 + 낮합성어둘 다 어근

따라서 형태소를 나눈 뒤에는 각 형태소가 어근·접사·어미 중 무엇인지를 한 번 더 판단해야 합니다.

9. 단어 길이와 형성 구조는 관계없다 — 두 글자라고 단일어, 길다고 복합어가 아니다

단어의 음절 수나 글자 수는 단일어·복합어 판정 기준이 아닙니다. 짧은 말도 복합어일 수 있고, 긴 말도 하나의 어근으로 분석되는 단일어일 수 있습니다.

보이는 길이보다 내부 구조
“몇 글자인가?”를 묻지 말고 “의미의 중심인 어근이 몇 개인가, 접사가 붙었는가?”를 묻습니다.

특히 처음 보는 단어는 겉모양만으로 쪼개지 말고 사전의 형태 정보, 실제 의미 관계, 학교 문법의 분석 기준을 함께 확인해야 합니다.

10. 한자어와 경계 사례 — 모든 단어가 하나의 답으로 고정되는 것은 아니다

국립국어원 온라인가나다는 조어 판단에는 문법적 견해 차이가 있을 수 있으며, 같은 단어도 분석이 달라질 수 있다고 안내합니다. 특히 두 음절 한자어는 각 한자를 독립적인 요소로 볼지, 하나의 어근으로 굳어진 단어로 볼지에 따라 단일어와 복합어 판단이 달라질 수 있습니다.

따라서 시험이나 교과 학습에서는 교과서와 출제 기준을 우선하고, 사전과 문법서에서 분석이 엇갈리는 단어를 억지로 하나의 절대 답으로 만들지 않는 것이 좋습니다.

경계 사례 처리 원칙
구조가 분명한 예로 기본 규칙을 익힌 뒤, 견해차가 있는 단어는 별도 예외·심화 사례로 다룹니다. 기본 개념을 경계 사례로부터 정의하면 오히려 체계가 흐려집니다.

11. 실전 판별 순서 — 어미를 빼고, 어근 수와 접사를 확인한다

1활용 부분 제외용언이면 어미를 먼저 단어 형성 판정에서 제외합니다.
2어근 수 확인의미의 중심이 되는 어근이 하나인지 둘 이상인지 봅니다.
3접사 확인어근 앞뒤에 새 단어를 만드는 접사가 있는지 봅니다.
4최종 분류한 어근이면 단일어, 어근+어근이면 합성어, 접사가 있으면 파생어로 정리합니다.
  • 단일어와 복합어는 단어의 길이가 아니라 형성 구조로 나눕니다.
  • 복합어는 합성어와 파생어를 포함합니다.
  • 합성어는 둘 이상의 어근 결합이 핵심입니다.
  • 파생어는 접사의 결합이 핵심입니다.
  • 어미는 단어 형성 분류의 조어 요소로 세지 않습니다.
  • 경계 사례는 교과서·사전·문법서의 분석 기준을 확인합니다.

12. 다단계 형성 — 단어는 한 번에만 만들어지는 것이 아니다

실제 단어는 한 번의 결합으로 끝나지 않을 수 있습니다. 이미 만들어진 단어에 다시 어근이나 접사가 결합하면서 더 긴 단어가 만들어지기도 합니다. 예를 들어 합성 뒤에 다시 합성이 일어나거나, 파생된 단어에 또 다른 요소가 붙을 수 있습니다.

이때는 완성된 단어를 한 번에 모두 잘게 쪼개기보다 마지막 형성 단계에서 어떤 두 구성 요소가 직접 결합했는지를 살피는 직접 구성 성분 분석이 도움이 됩니다.

전체 분류 → 마지막 결합 → 내부 단계
먼저 단일어·합성어·파생어의 큰 체계를 잡고, 복잡한 단어는 마지막 결합부터 단계적으로 분석합니다. 다단계 형성은 뒤의 심화 글에서 별도로 다룹니다.

13. 한눈에 정리 — 단어 형성은 ‘어근 수 + 접사 유무’로 읽는다

유형기본 구조대표 예주의
단일어어근 1산, 하늘, 먹다용언의 어미는 제외
합성어어근 + 어근밤낮, 집안, 공부방단어와 구의 경계가 문제될 수 있음
파생어접사 + 어근 / 어근 + 접사덧신, 먹이, 풋고추접사와 어미를 구별
단어 형성의 핵심은 형태소를 많이 쪼개는 것이 아니라, 새 단어를 만든 구조를 읽는 것입니다.
어미를 제외하고 어근의 수와 접사의 유무를 확인하면 단일어·합성어·파생어의 전체 지도가 잡힙니다.
← 단어의 내부 구조← 어근과 접사← 접사
