단어와 어절 — 띄어쓰기 단위와 문법 단위의 차이

어절은 문장을 띄어쓰기로 나눈 마디이고, 단어는 문법적으로 하나의 말 단위입니다. 둘은 자주 같은 모양으로 보이지만, 조사가 앞말에 붙어 쓰이는 순간부터 수가 달라집니다.

1. 왜 단어와 어절을 따로 구분해야 하는가

문장에서 띄어 쓴 덩어리를 보면 자연스럽게 “이게 한 단어겠지”라고 생각하기 쉽습니다. 실제로 학교, 간다, 매우처럼 한 어절이 한 단어인 경우도 많습니다. 하지만 철수가, 책을처럼 조사가 붙은 표현은 한 어절 안에 두 단어가 들어 있습니다.

어절 = 띄어쓰기의 단위
단어 = 문법적으로 하나의 말 단위

국립국어원은 어절을 문장을 구성하는 각각의 마디이자 띄어쓰기의 단위로 설명합니다. 반면 표준국어대사전의 단어 정의에는 조사도 단어로 포함됩니다. 그래서 띄어쓰기만 세어서는 단어 수를 정확히 알 수 없습니다.

핵심은 ‘눈에 보이는 띄어쓰기’와 ‘문법적 단위’를 구별하는 것입니다.
어절은 표기에서 바로 확인할 수 있지만, 단어는 조사·의존 명사·용언 등 문법 지식이 있어야 정확히 셀 수 있습니다.

2. 단어와 어절 — 무엇을 기준으로 나누는가

구분단어어절
핵심 기준문법적으로 하나의 말 단위문장에서 띄어쓰기로 구분되는 마디
확인 방법품사와 문법 기능을 따져 봄실제 띄어쓰기 경계를 봄
조사의 처리표준국어대사전 관점에서는 별도의 단어앞말에 붙어서 한 어절을 이룸
대표 예철수 / 가철수가

학교 문법에서 어절은 문장 성분을 분석할 때 자주 쓰이는 단위이기도 합니다. 다만 문장의 구조를 더 세밀하게 설명할 때는 단어·구·절 같은 다른 단위도 함께 사용합니다.

3. “철수가 책을 읽었다” — 한 문장을 두 방식으로 나누기

“철수가 책을 읽었다.”를 먼저 띄어쓰기대로 나누어 봅시다.

철수가|책을|읽었다

띄어쓰기 경계는 두 곳이므로 어절은 3개입니다.

이번에는 단어로 나눕니다.

철수|가|책|을|읽었다
분석 단위나누기개수
어절철수가 / 책을 / 읽었다3
단어철수 / 가 / 책 / 을 / 읽었다5
같은 문장인데 3과 5가 나온 이유는 조사입니다.
‘가’와 ‘을’은 단어로 보지만 앞말에 붙여 쓰기 때문에 각각 ‘철수가’, ‘책을’이라는 한 어절 안에 들어갑니다.

4. 조사 때문에 단어 수와 어절 수가 달라진다

한글 맞춤법은 문장의 각 단어를 띄어 쓰는 것을 원칙으로 합니다. 그런데 조사는 예외적으로 앞말에 붙여 씁니다. 이 규칙 때문에 ‘단어’와 ‘어절’의 경계가 항상 일치하지 않습니다.

나는단어: 나 + 는 → 2개
어절: 나는 → 1개
학교에서단어: 학교 + 에서 → 2개
어절: 학교에서 → 1개
친구와단어: 친구 + 와 → 2개
어절: 친구와 → 1개
책까지단어: 책 + 까지 → 2개
어절: 책까지 → 1개
붙여 썼다고 해서 반드시 한 단어인 것은 아닙니다.
조사는 앞말에 붙어 쓰지만 독립된 품사이고, 표준국어대사전의 단어 정의에서도 단어로 처리됩니다.

5. 단어와 어절이 같은 경우 — 경계가 우연히 일치할 때

조사가 붙지 않은 많은 표현에서는 단어와 어절의 경계가 같습니다.

표현단어 수어절 수설명
학교11명사 한 단어가 그대로 한 어절
간다11활용형 전체가 동사 한 단어이자 한 어절
매우11부사 한 단어가 그대로 한 어절
오늘11명사·부사 용법과 무관하게 해당 문맥의 한 단어가 한 어절
경계가 같다고 개념까지 같은 것은 아닙니다.
‘학교’가 단어 1개이면서 어절 1개라고 해서 단어와 어절이 같은 개념이 되는 것은 아닙니다. 서로 다른 기준으로 나눈 결과가 이 경우에만 일치한 것입니다.

6. 한 어절 안에 여러 단어가 들어가는 대표 구조

학교 문법에서 가장 기본적인 구조는 체언 + 조사입니다. 조사는 앞말에 붙여 쓰므로 하나의 어절을 이루지만, 단어로 셀 때에는 각각 따로 봅니다.

어절단어 분석단어 수어절 수
학생이학생 + 이21
사과를사과 + 를21
집에서집 + 에서21
너만너 + 만21

반대로 용언의 어간과 어미는 여러 형태소로 나뉘지만, 단어 수를 셀 때는 활용형 전체를 한 단어로 봅니다. 따라서 ‘먹었다’는 형태소로는 여러 단위지만 단어 1개, 어절 1개입니다.

단어·어절 문제에 형태소 분석을 섞지 마십시오.
‘먹- / -었- / -다’로 나뉜다는 사실은 형태소 층위의 분석입니다. 단어와 어절을 셀 때는 ‘먹었다’ 전체를 하나의 단어이자 하나의 어절로 처리합니다.

7. 띄어쓰기 원칙과 어절 — 왜 ‘단어를 띄어 쓰는데’ 둘이 달라질까

한글 맞춤법 제2항은 문장의 각 단어를 띄어 쓰는 것을 원칙으로 합니다. 이 원칙만 보면 단어 수와 어절 수가 항상 같아야 할 것처럼 보입니다. 하지만 맞춤법 해설은 조사는 독립성이 없어 앞말에 붙여 쓴다고 설명합니다.

원칙: 단어마다 띄어 쓰기
예외적 결합: 조사는 앞말에 붙여 쓰기
결과: 한 어절 안에 두 단어가 들어갈 수 있음

국립국어원의 표준 문법 자료도 한국어의 어절은 띄어쓰기 단위와 대체로 일치하며, 조사와 어미 같은 문법 요소는 앞말에 붙어서 한 어절을 이룬다고 설명합니다.

어절은 ‘표기 결과’를 보는 단위이고, 단어는 ‘문법 구조’를 보는 단위라고 생각하면 쉽습니다.
띄어쓰기를 보면 어절은 바로 셀 수 있지만, 단어 수는 조사를 따로 분리하는 문법 분석이 필요합니다.

8. 단어 수와 어절 수를 세는 순서

1어절부터 세기띄어쓰기 경계대로 문장을 나눕니다.
2조사 찾기각 어절 끝에 붙은 조사가 있는지 확인합니다.
3단어로 분리조사는 앞말과 분리해 별도 단어로 셉니다.
4용언은 한 단어어간·어미로 쪼개지 않고 활용형 전체를 한 단어로 셉니다.
문장어절 수단어 수차이가 생기는 곳
철수가 왔다.23철수 + 가
나는 학생이다.23나 + 는
오늘 비가 온다.34비 + 가
친구와 학교에서 만났다.35친구 + 와, 학교 + 에서

9. 가장 많이 틀리는 판단 — 네 가지를 구분하기

  • “붙여 썼으면 한 단어다.” → 조사는 붙여 쓰지만 별도의 단어입니다.
  • “띄어쓰기 수만 세면 단어 수다.” → 조사 때문에 단어 수가 더 많아질 수 있습니다.
  • “용언은 어미마다 단어로 나눈다.” → 어미는 형태소이지만 단어가 아니므로 활용형 전체를 한 단어로 봅니다.
  • “단어와 어절은 항상 다른 수다.” → 조사가 없는 문장에서는 두 수가 같을 수도 있습니다.
문법 체계와 문제의 전제를 확인하십시오.
단어의 정의나 세부 경계는 문법 이론에 따라 차이가 있을 수 있습니다. 학교 학습에서는 교과서와 문제에서 제시한 분석 체계를 우선하는 것이 안전합니다.
시험에서는 먼저 “무엇을 세라는가”를 표시하십시오.
어절이면 띄어쓰기, 단어이면 품사와 조사, 형태소이면 최소 의미 단위를 기준으로 분석해야 합니다. 세 층위를 한꺼번에 섞으면 가장 쉽게 틀립니다.

10. 한눈에 정리 — 어절은 띄어쓰기 단위, 단어는 문법 단위다

확인 항목단어어절
무엇을 기준으로 하나문법적 말 단위띄어쓰기 경계
조사는 어떻게 보나별도 단어앞말과 한 어절
용언 활용형전체가 한 단어전체가 한 어절
‘책을’책 / 을 → 2단어책을 → 1어절
‘읽었다’1단어1어절
어절은 글에서 보이는 띄어쓰기의 마디이고, 단어는 그 안의 문법 구조를 따져 찾는 말의 단위입니다.
둘의 차이를 결정적으로 보여 주는 것은 조사입니다. ‘철수가 책을 읽었다’는 3어절이지만 5단어라는 사실을 기억하면 단어와 어절의 경계를 안정적으로 구분할 수 있습니다.
