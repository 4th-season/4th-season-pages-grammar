언어 단위 — 음운에서 담화까지 단위의 위계

음운부터 담화까지 하나의 문장을 여러 층위에서 읽습니다. 음절·형태소의 차이, 단어·어절의 구별, 구와 절의 판정, 기출에서 쓰는 판단 순서까지 연결합니다.

언어 단위는 작은 것부터 큰 것으로만 외우면 될까요?

문법을 처음 배울 때 언어 단위를 음운 → 음절 → 형태소 → 단어 → 어절 → 구 → 절 → 문장 → 담화처럼 한 줄로 외우는 경우가 많습니다. 전체 순서를 훑는 데에는 도움이 되지만, 모든 단위가 같은 기준으로 만들어진 것은 아닙니다.

예를 들어 음절은 소리 조직의 단위이고, 형태소는 의미나 문법 기능을 가진 최소 단위입니다. 둘을 단순히 크기만으로 비교하면 중요한 차이를 놓칠 수 있습니다.

핵심
언어 단위는 ‘크기’만이 아니라 무엇을 분석하기 위한 단위인가를 기준으로 이해해야 합니다.

예를 들어 바다는 두 음절(바·다)이면서, 학교 문법의 일반적인 분석에서는 하나의 형태소입니다. 음절과 형태소가 같은 크기 단위라면 설명하기 어려운 사례입니다. 따라서 먼저 소리를 묻는지, 뜻·문법 기능을 묻는지 구분해야 합니다.

1. 음운 — 뜻을 구별해 주는 가장 작은 소리 단위

음운은 말의 뜻을 구별하는 데 기능하는 최소 소리 단위입니다.

불과 풀은 첫소리 /ㅂ/과 /ㅍ/의 차이로 뜻이 달라집니다.

이처럼 하나의 소리 차이가 낱말의 뜻을 갈라 놓는다면 그 소리는 음운 체계에서 중요한 단위가 됩니다.

음운은 실제 물리적 소리인 음성과 구별해 생각할 필요가 있습니다. 문법에서는 자음·모음과 같은 음운이 어떤 체계를 이루고, 실제 발음에서 어떻게 변하는지까지 살펴봅니다.

2. 음절 — 소리의 한 덩어리

음절은 실제 발음에서 한 번에 묶여 나오는 소리의 단위입니다.

낱말음절 수예
집1집
학교2학-교
한국어3한-국-어

음절은 초성·중성·종성의 결합으로 설명할 수 있습니다. 하지만 음절과 형태소는 같은 기준의 단위가 아닙니다. 한 형태소가 한 음절일 수도 있고 여러 음절일 수도 있습니다.

3. 형태소 — 의미나 문법 기능을 가진 최소 단위

형태소는 뜻이나 문법 기능을 가진 최소 단위입니다.

먹었다 → 먹- + -었- + -다
  • 먹- : 어휘적 의미의 중심
  • -었- : 시간과 관련된 문법 의미
  • -다 : 문장을 종결하는 기능

형태소는 음절 수와 일치하지 않을 수 있습니다. 중요한 것은 더 나누었을 때 의미나 기능이 유지되는가입니다.

4. 단어 — 문법적으로 자립성을 가지는 기본 단위

단어는 문법에서 가장 자주 사용하는 기본 단위입니다. 명사·동사·형용사·조사·부사 같은 품사는 단어를 분류한 결과입니다.

학생이 책을 읽었다.

학생 / 이 / 책 / 을 / 읽었다

학교 문법에서는 조사를 하나의 단어로 다룹니다. 그래서 띄어쓰기 단위인 어절과 단어가 항상 일치하지는 않습니다.

판별 기준 학교 문법에서는 조사도 단어로 처리하지만, 어간에 붙은 어미는 보통 독립된 단어로 세지 않습니다. 따라서 학생이 / 책을 / 읽었다는 세 어절이지만, 학생·이·책·을·읽었다의 다섯 단어로 분석됩니다.

5. 어절 — 띄어쓰기와 밀접한 문장 표면 단위

어절은 문장에서 띄어 쓴 덩어리를 기준으로 보는 단위입니다.

학생이 / 책을 / 읽었다.

이 문장은 세 어절이지만 단어 수는 더 많을 수 있습니다. 학생이는 명사 학생과 조사 이로 이루어진 하나의 어절입니다.

주의 단어와 어절은 자주 겹치지만 같은 개념은 아닙니다.

6. 구 — 둘 이상의 단어가 모여 하나의 덩어리처럼 기능하는 단위

국립국어원 표준국어대사전은 구를 둘 이상의 단어가 모여 절이나 문장의 일부를 이루는 토막으로 풀이합니다. 구는 일반적으로 주어와 서술어의 관계를 갖지 않습니다.

아주 예쁜 꽃

학교 앞 작은 서점

이 표현들은 여러 단어가 모였지만 그 자체로 완전한 주어-서술어 관계를 이루지는 않습니다.

이때 ‘아주 예쁜 꽃’ 전체는 구로 볼 수 있지만, 내부의 ‘예쁜’이 관형사형 어미를 가진 용언의 활용형이라는 이유만으로 그 덩어리 전체를 절이라 부르는 것은 아닙니다. 절의 판정에서는 주어와 서술어의 관계가 설정되는가를 검토해야 합니다. 문맥에서 주어가 생략될 수도 있어 형태만 보고 단정하지 않습니다.

7. 절 — 주어와 서술어의 관계를 가진 문장 내부 단위

절은 보통 주어와 서술어의 관계를 갖지만, 더 큰 문장 안에서 하나의 성분처럼 쓰일 수 있습니다.

나는 비가 오는 것을 보았다.

비가 오는에는 주어 비가와 서술어 오는의 관계가 있습니다. 하지만 전체 문장 안에서는 더 큰 구조의 일부입니다.

절을 이해하면 안은문장과 이어진문장, 관형절·명사절·부사절 같은 문장 구조를 분석하기 쉬워집니다.

8. 문장 — 하나의 완결된 생각을 표현하는 단위

문장은 일정한 종결성을 가지며 하나의 생각이나 판단, 질문, 명령 등을 표현합니다.

비가 온다.

오늘 비가 오니?

문을 닫아라.

문장은 한 절로 이루어질 수도 있고 여러 절이 결합할 수도 있습니다. 그래서 문장 구조를 분석할 때는 절의 수와 관계를 함께 봅니다.

9. 담화 — 문장을 넘어 맥락 속에서 이어지는 의미 단위

실제 의사소통은 한 문장으로 끝나지 않습니다.

가: 민수 왔어?

나: 응, 조금 전에.

둘째 발화에는 주어와 서술어가 완전히 드러나 있지 않지만 앞 문장과 상황을 공유하기 때문에 의미를 이해할 수 있습니다.

담화는 여러 문장과 발화가 맥락 속에서 연결되어 하나의 의미 흐름을 이루는 단위입니다. 여기에서는 지시·생략·대용·접속·화자와 청자의 관계가 중요해집니다.

10. 언어 단위는 왜 한 줄 위계로만 보면 안 될까요?

언어 단위는 서로 연결되지만 설정 기준이 다릅니다.

단위주된 기준
음운뜻을 구별하는 소리
음절발음의 소리 덩어리
형태소의미·문법 기능의 최소 단위
단어문법적 기본 단위
어절띄어쓰기 중심의 표면 단위
구둘 이상의 단어가 이룬 문장 내부 덩어리
절주어와 서술어 관계를 가진 내부 구조
문장완결된 생각을 표현하는 단위
담화맥락 속에서 이어지는 문장·발화의 의미 단위

따라서 ‘무엇이 더 큰가’보다 무엇을 분석하기 위해 설정된 단위인가를 먼저 묻는 편이 정확합니다.

11. 실제 문장을 여러 단위로 나누어 봅시다

학생들이 새 책을 읽었다.
단위분석 예
음절학-생-들-이 / 새 / 책-을 / 읽-었-다
형태소학생 + 들 + 이 / 새 / 책 + 을 / 읽- + -었- + -다
어절학생들이 / 새 / 책을 / 읽었다
문장 성분학생들이(주어) / 새(관형어) / 책을(목적어) / 읽었다(서술어)
문장전체 표현 하나

같은 표현을 여러 방식으로 나눌 수 있는 것은 분석이 제멋대로라서가 아니라, 서로 다른 단위를 기준으로 보고 있기 때문입니다.

※ ‘학생들이’는 학생+들+이로, ‘읽었다’는 읽-+-었-+-다로 분석합니다. 새는 품사로는 관형사, 문장 성분으로는 관형어입니다. 서로 다른 분류 질문을 섞지 않는 것이 중요합니다.

12. 소리의 단위와 의미의 단위를 구분하는 두 갈래

언어 단위를 음운 → 음절 → 형태소 → 단어라는 하나의 계단으로만 외우면, ‘음절이 형태소의 부품인가?’ 같은 질문에 막힙니다. 음운과 음절은 발음과 소리 조직을 중심으로, 형태소와 단어는 뜻·기능·결합을 중심으로 설정되기 때문입니다.

소리 분석의 축

음운 — 단어의 의미를 구별해 주는 소리의 단위

음절 — 발음에서 묶여 실현되는 소리의 단위

‘바다’는 바·다, 두 음절입니다.

형태·문장 분석의 축

형태소 — 의미 또는 문법 기능을 가진 최소 단위

단어 — 학교 문법에서 품사 분류의 기준이 되는 단위

‘바다’는 보통 한 형태소로 분석됩니다.

그 위로 구와 절은 문장 내부의 구성 방식, 문장은 종결성을 지닌 언어 표현, 담화는 앞뒤 발화와 맥락의 연결을 분석하는 개념입니다. 단위 사이에는 포함 관계가 나타날 수 있지만, 모든 단위를 단일한 크기 척도로 재단해서는 안 됩니다.

첫 질문 문항이 ‘몇 음절인가’를 물으면 발음 단위로, ‘몇 형태소인가’를 물으면 의미·기능 단위로, ‘몇 어절인가’를 물으면 띄어쓰기 단위로 돌아가야 합니다.

13. 단어와 어절, 구와 절을 실제로 구별해 봅시다

다음 세 문장을 비교해 보겠습니다.

① 학생이 책을 읽었다.

② 아주 작은 집

③ 학생이 읽은 책이 재미있다.

분석할 것판단 근거분석 결과
① 어절띄어 쓴 마디학생이 / 책을 / 읽었다 → 3어절
① 단어조사를 단어로 세되 어미는 별도 단어로 세지 않음학생 / 이 / 책 / 을 / 읽었다 → 5단어
② 구여러 단어가 하나의 명사구로 기능하며 덩어리 전체에 독립된 주어·서술어의 짝이 없음‘아주 작은 집’은 구로 분석할 수 있음
③ 절‘학생이 읽은’에 주어 ‘학생이’와 서술어 ‘읽은’의 관계가 있음전체 문장 속에 관형절이 안겨 있음

단어·어절은 어디를 나눌 것인가가 핵심이고, 구·절은 나눈 덩어리 안에 어떤 문장 구조가 형성되는가가 핵심입니다. 특히 수식 기능이 있다고 해서 언제나 관형사인 것도, 관형절인 것도 아닙니다.

14. 실제 기출: 언어 단위와 선택·통합 관계를 어떻게 판단할까요?

2004학년도 대학수학능력시험 국어 영역 36번은 ‘언어의 체계·선택·구조’에 대한 독서 지문을 바탕으로, 짧은 글에서 부분과 전체의 관계를 판단하게 합니다. 지문은 대체 가능한 요소들의 선택 관계와, 여러 요소가 결합하여 구조를 이루는 통합 관계를 구분합니다.

문항에 등장한 문장들은 담화를 구성하고, 문장 속의 단어와 표현들은 다시 작은 구성 요소로 분석될 수 있습니다. 여기서 중요한 것은 두 표현이 같은 자리에서 서로 대체 가능한가, 아니면 동시에 결합하여 더 큰 단위를 이루는가를 분리하는 것입니다.

  1. 발문이 요구하는 판단을 확인합니다. 전체 글의 구조, 구성 요소, 선택 관계, 통합 관계 중 무엇이 문제인지 표시합니다.
  2. 문제의 각 표시가 단어·문장·담화 중 어느 층위에 놓이는지 정합니다. 서로 다른 층위의 항목은 단순히 나란히 비교하지 않습니다.
  3. 서로 바꾸어 넣는 관계라면 선택 관계, 실제 표현 속에 이어지거나 포함되는 관계라면 통합 관계인지 검토합니다.
  4. 각 선지의 주장에 대해 해당 위치에서 대체가 가능한지 / 함께 결합한 요소인지를 원문과 대조한 뒤 결론을 냅니다.
기출 원문 대조 범위 2004학년도 수능 36번의 발문·제시문·선지 내용은 수능 DB에서 확인했습니다. 이 글은 정답 번호 자체보다 문제를 해결하는 판단 절차를 설명하며, 최종 채점용 정답·오답 해설은 공식 정답표와 별도 대조 후 확정합니다.

관련 개념을 더 자세히 확인하려면 규칙과 체계 및 언어 단위의 위계를 이어서 읽을 수 있습니다.

15. 어떤 개념글부터 읽어야 할까요?

이 글은 언어 단위 전체의 지도입니다. 개별 개념을 깊이 판단해야 할 때는 해당 하위 글로 이동하는 편이 낫습니다.

언어 단위의 위계작은 구성 요소가 큰 언어 구조를 이루는 방식을 분석 형태·기능·의미같은 표현을 서로 다른 세 기준에서 분류 품사와 문장 성분단어 자체의 성질과 문장 속 역할을 구별 문법 분석 방법발문을 보고 어떤 분석 단위를 택할지 결정

기출문제에 접근할 때는 문항을 먼저 읽고 → 요구하는 분석 단위를 확인하고 → 해당 개념글에서 판정 기준을 찾아 → 선지에 적용하는 순서가 효율적입니다. 여러 개념이 등장해도 모두가 그 문항의 필수 풀이 개념인 것은 아닙니다.
