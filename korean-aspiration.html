거센소리되기란 무엇인가 — ㅎ과 평음이 만나 거센소리가 되는 현상

거센소리되기는 ‘ㅎ’과 평음이 만나 둘이 따로 발음되지 않고 하나의 거센소리로 줄어드는 음운 변동입니다. ‘놓고[노코]’의 ㅎ+ㄱ→ㅋ, ‘먹히다[머키다]’의 ㄱ+ㅎ→ㅋ처럼 결합 방향은 앞뒤가 바뀔 수 있지만 핵심은 같습니다.

목차
  1. 거센소리되기는 왜 축약인가
  2. ㅎ 뒤의 ㄱ·ㄷ·ㅈ
  3. 평음 뒤의 ㅎ
  4. ㅂ+ㅎ에서 ㅍ이 되는 경우
  5. 겹받침에서는 무엇이 먼저 일어나는가
  6. 용언 어간+접미사와 그 밖의 경우
  7. ㅎ 탈락과 구별하기
  8. 된소리되기와 구별하기
  9. 문제에서 분석하는 순서
  10. 한눈에 정리

1. 거센소리되기는 왜 ‘축약’인가

축약은 둘 이상의 음운이 결합하여 더 적은 수의 음운으로 줄어드는 변화입니다. 거센소리되기에서는 ‘ㅎ’과 평음이 각각 따로 남지 않고, 두 소리의 성질이 합쳐진 거센소리 하나로 실현됩니다.

ㅎ + ㄱ → ㅋ · ㅎ + ㄷ → ㅌ · ㅎ + ㅈ → ㅊ
ㄱ + ㅎ → ㅋ · ㄷ + ㅎ → ㅌ · ㅂ + ㅎ → ㅍ · ㅈ + ㅎ → ㅊ
판별 기준
‘ㅎ이 안 들린다’고 해서 곧바로 탈락이라고 하면 안 됩니다. ㅎ의 성질이 뒤나 앞의 평음과 합쳐져 ㅋ·ㅌ·ㅍ·ㅊ이라는 새 거센소리 하나로 남으면 축약입니다.

2. ㅎ 뒤에 ㄱ·ㄷ·ㅈ이 오면 — ㅋ·ㅌ·ㅊ

표준 발음법 제12항 1은 받침 ‘ㅎ(ㄶ, ㅀ)’ 뒤에 ㄱ·ㄷ·ㅈ이 결합하면 두 소리를 합쳐 각각 [ㅋ·ㅌ·ㅊ]으로 발음한다고 규정합니다.

형태결합표준 발음
놓고ㅎ + ㄱ → ㅋ[노코]
좋던ㅎ + ㄷ → ㅌ[조ː턴]
쌓지ㅎ + ㅈ → ㅊ[싸치]
많고ㄶ의 ㅎ + ㄱ → ㅋ[만ː코]
않던ㄶ의 ㅎ + ㄷ → ㅌ[안턴]
닳지ㅀ의 ㅎ + ㅈ → ㅊ[달치]

ㄶ·ㅀ에서는 ㄴ·ㄹ이 남고 ㅎ이 뒤의 평음과 합쳐지는 모습이 드러납니다. 그래서 ‘많고[만코]’를 단순한 ㅎ 탈락으로 처리하면 변화의 핵심을 놓치게 됩니다.

3. 평음 뒤에 ㅎ이 와도 — 다시 하나의 거센소리

제12항의 붙임 1은 방향이 반대인 경우도 규정합니다. 받침 ㄱ·ㄷ·ㅂ·ㅈ이 뒤 음절 첫소리 ㅎ과 만나면 [ㅋ·ㅌ·ㅍ·ㅊ]으로 발음합니다.

형태결합표준 발음
각하ㄱ + ㅎ → ㅋ[가카]
먹히다ㄱ + ㅎ → ㅋ[머키다]
맏형ㄷ + ㅎ → ㅌ[마텽]
좁히다ㅂ + ㅎ → ㅍ[조피다]
꽂히다ㅈ + ㅎ → ㅊ[꼬치다]
앉히다ㄵ의 ㅈ + ㅎ → ㅊ[안치다]
방향보다 결과가 중요합니다.
ㅎ이 앞에 있든 뒤에 있든, 평음과 결합해 거센소리 하나가 되면 거센소리되기입니다.

4. ㅂ + ㅎ → ㅍ — 앞 방향에서는 ㅍ도 생긴다

ㅎ 뒤에는 제12항 본문이 ㄱ·ㄷ·ㅈ을 제시하므로 결과가 ㅋ·ㅌ·ㅊ입니다. 반대로 평음 뒤에 ㅎ이 오는 붙임 1에는 ㅂ도 포함됩니다. 그래서 ‘좁히다[조피다]’, ‘넓히다[널피다]’처럼 [ㅍ]이 생길 수 있습니다.

좁- + -히- → [조피-]ㅂ과 ㅎ이 합쳐져 ㅍ 하나가 됩니다.
넓- + -히- → [널피-]겹받침 ㄼ 가운데 ㅂ과 접미사 ㅎ의 결합이 직접 축약됩니다.

이 차이는 ‘거센소리되기 결과는 항상 ㅋ·ㅌ·ㅊ뿐’이라고 외우면 놓치기 쉽습니다. ㅎ의 위치와 결합하는 평음의 종류를 함께 보아야 합니다.

5. 겹받침에서는 무엇이 먼저 일어나는가

거센소리되기 자체는 단순하지만 겹받침이 끼면 분석 순서가 복잡해집니다. 특히 용언 어간 뒤에 접미사가 붙는 경우와, 단순히 다른 말이 이어지는 경우가 같지 않을 수 있습니다.

닭하고 → [다카고]
국립국어원은 이런 경우 먼저 겹받침의 발음 규칙에 따라 자음군 단순화가 적용된 뒤, 남은 평음과 ㅎ이 결합해 거센소리가 되는 것으로 설명합니다.
넓히다 → [널피다]
반면 용언 어간 뒤에 접미사 ‘-히-’가 결합한 경우에는 어간의 관련 평음과 ㅎ이 직접 줄어드는 것으로 표준 발음법 해설이 설명합니다.

6. ‘용언 어간 + 접미사’인지가 중요한 이유

표준 발음법 제12항 해설은 평음 뒤에 ㅎ이 오는 경우, ‘꽂히다·넓히다’처럼 용언 어간 뒤에 접미사가 결합하는 경우와 그렇지 않은 경우를 구별할 필요가 있다고 밝힙니다.

용언 어간 + -히-→평음 + ㅎ 직접 축약→거센소리
그 밖의 결합→대표음화·자음군 단순화→남은 평음 + ㅎ 축약

따라서 ‘표면에 겹받침이 있으니 무조건 자음군 단순화부터’라고 기계적으로 적용하지 않습니다. 형태소의 성격과 결합 관계까지 확인해야 분석이 정확해집니다.

7. ㅎ 탈락과 거센소리되기 — ㅎ이 사라졌는가, 합쳐졌는가

현상대표 환경예판별
ㅎ 탈락ㅎ(ㄶ·ㅀ) + 모음 시작 어미·접미사놓아[노아], 많아[마ː나]ㅎ이 결과에 남지 않음
거센소리되기ㅎ + 평음 또는 평음 + ㅎ놓고[노코], 먹히다[머키다]ㅎ의 성질이 거센소리에 남음
가장 쉬운 질문
ㅎ이 없어지고 다른 소리만 남았는가? → 탈락. ㅎ과 평음이 합쳐져 ㅋ·ㅌ·ㅍ·ㅊ이 되었는가? → 거센소리되기(축약).

8. 된소리되기와 거센소리되기 — ‘세진 소리’라고 같은 현상이 아니다

된소리와 거센소리는 모두 예사소리보다 강하게 들릴 수 있지만 음운 체계에서는 다른 계열입니다. 된소리되기는 ㄲ·ㄸ·ㅃ·ㅆ·ㅉ이 되는 변화이고, 거센소리되기는 ㅋ·ㅌ·ㅍ·ㅊ이 되는 변화입니다.

국밥 [국빱]ㅂ이 ㅃ으로 바뀜 → 된소리되기
좋고 [조코]ㅎ+ㄱ이 ㅋ으로 줄어듦 → 거센소리되기

거센소리되기는 두 음운이 하나로 줄어들어 음운 수가 감소한다는 점에서 축약으로 분류됩니다. 된소리되기는 보통 음운 수가 유지되는 교체입니다.

9. 문제에서 분석하는 순서

1원형 복원ㅎ과 평음이 실제 형태에 있는지 봅니다.
2방향 확인ㅎ+평음인지, 평음+ㅎ인지 확인합니다.
3형태소 관계 확인용언 어간+접미사인지, 일반 결합인지 봅니다.
4중간 과정 분리필요하면 대표음화·자음군 단순화를 먼저 적용합니다.
  • 놓고·좋던·쌓지는 ㅎ 뒤의 평음이 거센소리로 축약됩니다.
  • 각하·먹히다·맏형·좁히다·꽂히다는 평음 뒤의 ㅎ과 축약됩니다.
  • 넓히다처럼 용언 어간+접미사에서는 관련 평음과 ㅎ이 직접 줄어들 수 있습니다.
  • 닭하고처럼 일반 결합에서는 자음군 단순화 뒤에 거센소리되기가 이어질 수 있습니다.
  • 놓아[노아]처럼 ㅎ 자체가 없어지는 경우는 ㅎ 탈락입니다.
  • 국밥[국빱]처럼 된소리가 생기는 경우는 거센소리되기가 아닙니다.

10. 한눈에 정리

구조결과대표 예
ㅎ + ㄱㅋ놓고[노코], 많고[만ː코]
ㅎ + ㄷㅌ좋던[조ː턴], 않던[안턴]
ㅎ + ㅈㅊ쌓지[싸치], 닳지[달치]
ㄱ + ㅎㅋ각하[가카], 먹히다[머키다]
ㄷ + ㅎㅌ맏형[마텽]
ㅂ + ㅎㅍ좁히다[조피다], 넓히다[널피다]
ㅈ + ㅎㅊ꽂히다[꼬치다], 앉히다[안치다]
거센소리되기의 핵심은 ‘ㅎ이 없어졌는가’가 아니라 ‘ㅎ과 평음이 하나의 거센소리로 합쳐졌는가’입니다.
겹받침이 끼어 있을 때에는 형태소 관계와 선행 음운 변동의 순서까지 추적해야 정확한 분석이 됩니다.
