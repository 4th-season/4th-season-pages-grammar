단어와 형태소 — 최소 의미 단위와 문법 단위의 차이

형태소는 뜻을 가진 가장 작은 단위이고, 단어는 문장에서 하나의 문법 단위로 기능하는 말입니다. 그래서 둘은 자주 겹치지만 같은 단위는 아닙니다. 한 단어가 여러 형태소로 이루어지는 순간을 보면 차이가 선명해집니다.

1. 왜 단어와 형태소를 따로 구분해야 하는가

‘책’, ‘사람’처럼 간단한 말만 보면 단어와 형태소가 비슷해 보입니다. ‘책’은 하나의 형태소이면서 동시에 하나의 단어이기 때문입니다. 하지만 책가방이나 먹었다처럼 내부가 더 나뉘는 말을 보면 두 단위가 달라집니다.

형태소 = 뜻을 가진 최소 단위
단어 = 문장에서 하나의 문법 단위로 기능하는 말

국립국어원 자료도 단어를 형태소보다 크거나 같은 문법 단위로 설명합니다. 즉 형태소 하나가 그대로 단어가 될 수도 있지만, 여러 형태소가 모여 하나의 단어를 이룰 수도 있습니다.

핵심은 층위가 다르다는 점입니다.
형태소 분석은 “더 쪼갤 수 있는가?”를 묻고, 단어 분석은 “문장에서 어디까지 하나의 문법 단위인가?”를 묻습니다.

2. 형태소와 단어 — 무엇을 기준으로 나누는가

구분형태소단어
핵심 기준뜻을 가진 가장 작은 단위문장에서 기능하는 문법 단위
더 나눌 수 있는가의미를 유지하며 더 나누면 형태소가 아님내부가 여러 형태소로 나뉠 수 있음
대표 예먹- / -었- / -다먹었다
분석 목적말의 최소 의미 요소 찾기문법적으로 독립된 말 단위 찾기

형태소의 ‘뜻’에는 사물이나 행동 같은 어휘적 의미뿐 아니라 시제·문법 관계 같은 문법적 기능도 포함됩니다. 그래서 ‘-었-’이나 조사 ‘을’도 형태소입니다.

3. 하나의 형태소가 하나의 단어인 경우

가장 단순한 경우는 형태소 하나가 그대로 단어 하나가 되는 경우입니다.

집더 나누면 본래 의미를 유지하는 작은 단위가 남지 않습니다. 형태소 1개, 단어 1개입니다.
책하나의 어휘적 의미를 가진 최소 단위이면서 문장에서 명사 한 단어로 쓰입니다.
나대명사 하나가 하나의 형태소이면서 하나의 단어입니다.
가주격 조사 ‘가’도 하나의 형태소이며, 표준국어대사전의 관점에서는 하나의 단어로 봅니다.
이런 예만 보면 ‘형태소 = 단어’처럼 느껴질 수 있습니다.
하지만 이것은 두 단위가 같은 것이 아니라, 우연히 경계가 일치한 경우입니다.

4. 여러 형태소가 하나의 단어인 경우

단어와 형태소의 차이가 가장 잘 드러나는 경우입니다. 하나의 단어 안에 둘 이상의 형태소가 들어갈 수 있습니다.

책가방책 + 가방 → 형태소 2개가 합쳐져 단어 1개를 이룹니다.
풋사과풋- + 사과 → 접사가 붙어도 결과 전체는 단어 1개입니다.
먹었다먹- + -었- + -다 → 형태소 3개지만 활용형 전체는 동사 한 단어입니다.
읽겠습니다읽- + -겠- + -습니다 → 여러 형태소가 결합해도 하나의 용언 단어로 기능합니다.
단어 안을 다시 형태소로 분석할 수 있다는 점이 중요합니다.
단어는 형태소보다 큰 층위이므로, 단어 내부에 어근·접사·어간·어미 같은 여러 형태소가 들어갈 수 있습니다.

5. 형태소이지만 단어가 아닌 경우 — 어미와 접사

모든 형태소가 단어인 것은 아닙니다. 대표적으로 어미와 접사는 형태소이지만 일반적인 학교 문법과 표준국어대사전의 관점에서는 단어로 보지 않습니다.

형태형태소인가단어인가이유
-었-예아니오과거 시제라는 문법 기능을 가진 어미
-다예아니오문장을 끝맺는 어미
풋-예아니오다른 말에 붙어 새 단어를 만드는 접두사
-개예아니오어근에 붙어 새 명사를 만드는 접미사
‘뜻이 있으면 단어다’라는 판단은 틀립니다.
‘-었-’은 과거라는 뜻과 기능이 있지만 단어가 아닙니다. 형태소 여부와 단어 여부는 서로 다른 기준으로 판단해야 합니다.

6. 조사는 왜 특별한가 — 형태소이면서 단어

조사는 다른 말에 붙어 쓰이므로 겉으로는 어미나 접사와 비슷해 보입니다. 그러나 표준국어대사전은 조사를 단어에 포함합니다. 따라서 ‘책을’에서 ‘을’은 형식 형태소이면서 동시에 조사라는 단어입니다.

책+을→책을
단위분석개수
형태소책 / 을2
단어책 / 을2
어절책을1

이 예는 세 층위를 한꺼번에 보여 줍니다. 붙여 쓴다고 해서 한 단어인 것은 아니며, 형태소 수와 단어 수가 같다고 해서 형태소와 단어가 같은 개념인 것도 아닙니다.

7. 같은 문장을 형태소와 단어 두 층위로 분석하기

“철수가 밥을 먹었다.”를 형태소와 단어 단위로 나누어 보면 기준의 차이가 선명합니다.

분석 층위나누기개수
형태소철수 / 가 / 밥 / 을 / 먹- / -었- / -다7
단어철수 / 가 / 밥 / 을 / 먹었다5
차이는 ‘먹었다’에서 생깁니다.
형태소 분석에서는 먹-·-었-·-다로 나누지만, 단어 분석에서는 활용된 동사 전체를 한 단어로 셉니다.

국립국어원 온라인가나다에서도 하나의 문장을 형태소 단위와 단어 단위로 다르게 나누는 분석이 가능함을 확인할 수 있습니다. 이것이 바로 두 단위가 서로 다른 층위라는 실제적인 증거입니다.

8. 형태소 수와 단어 수를 세는 법

1먼저 단어를 찾기명사·대명사·용언·조사 등 문법적으로 한 단위로 보는 말을 찾습니다.
2단어 내부 보기각 단어가 더 작은 의미 단위로 나뉘는지 확인합니다.
3어미·접사 분리활용형과 파생어에서는 어미나 접사를 형태소로 따로 셉니다.
4조사 다시 확인조사는 앞말에 붙여 쓰지만 단어로 세는지 확인합니다.
표현형태소 분석형태소 수단어 수
집집11
책가방책 + 가방21
풋사과풋- + 사과21
먹었다먹- + -었- + -다31
책을책 + 을22

9. 가장 많이 틀리는 판단 — 네 가지를 버리기

  • “띄어 쓰지 않으면 한 단어다.” → 조사는 붙여 쓰지만 별개의 단어로 봅니다.
  • “뜻이 있으면 모두 단어다.” → 어미와 접사도 뜻·기능을 가진 형태소지만 단어는 아닙니다.
  • “단어 하나에는 형태소 하나만 있다.” → 합성어·파생어·활용형에는 여러 형태소가 들어갈 수 있습니다.
  • “형태소 수와 단어 수는 항상 같다.” → ‘먹었다’는 형태소 3개, 단어 1개입니다.
세부 분석에는 문법 체계에 따른 차이가 있을 수 있습니다.
국립국어원도 형태소 분석이나 단어 경계 일부는 학자와 문법 체계에 따라 달라질 수 있다고 안내합니다. 학교 학습에서는 교과서의 분석 체계를 우선하십시오.
시험에서는 질문의 층위를 먼저 표시하십시오.
‘형태소로 나누라’는지, ‘단어 수를 세라’는지, ‘어절 수를 세라’는지를 먼저 확인하면 같은 문장을 서로 다른 기준으로 섞어 분석하는 실수를 줄일 수 있습니다.

10. 한눈에 정리 — 형태소와 단어는 겹칠 수 있지만 같은 단위가 아니다

확인 질문형태소단어
무엇을 찾는가뜻을 가진 최소 요소문장에서 기능하는 말 단위
한 단어 안에 여러 개가 들어갈 수 있는가예해당 없음
어미·접사는 포함되는가예아니오
조사는 포함되는가예표준국어대사전 관점에서는 예
대표 비교먹- / -었- / -다먹었다
형태소는 단어를 이루는 최소 의미 재료이고, 단어는 그 재료가 문장에서 하나의 문법 단위로 묶인 결과입니다.
둘의 경계가 같을 때도 있지만 항상 같지는 않습니다. 이 차이를 이해하면 이후의 어근·접사, 어간·어미, 단일어·복합어 분석이 훨씬 쉬워집니다.
