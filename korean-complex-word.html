복합어란 무엇인가 — 둘 이상의 형태소가 결합한 단어의 구조

복합어는 단어 형성에 참여하는 둘 이상의 요소가 결합해 만들어진 단어입니다. 합성어와 파생어가 모두 복합어에 들어갑니다. 다만 형태소가 두 개 이상 보인다고 모두 복합어인 것은 아닙니다.

1. 복합어의 정확한 뜻 — 단어 형성에 둘 이상의 요소가 참여한 단어

학교 문법에서 단어를 형성 방식으로 나누면 크게 단일어와 복합어로 볼 수 있습니다. 단일어는 하나의 어근으로 이루어진 단어이고, 복합어는 둘 이상의 조어 요소가 결합해 만들어진 단어입니다.

단어 → 단일어 / 복합어 → 합성어 / 파생어

복합어라는 이름만 보면 ‘형태소가 둘 이상인 모든 단어’라고 생각하기 쉽습니다. 그러나 실제 판별에서는 그 형태소가 단어 형성에 참여했는지를 따져야 합니다. 활용을 나타내는 어미까지 모두 세면 ‘먹다’ 같은 단일어도 잘못 복합어로 분류하게 됩니다.

복합어의 핵심
둘 이상의 형태소가 보인다는 사실보다, 둘 이상의 조어 요소가 결합해 새 단어가 만들어졌는가가 중요합니다.

2. 단일어와 복합어 — 가장 먼저 가르는 기준

구분형성 구조예
단일어하나의 어근산, 하늘, 먹다, 푸르다
복합어둘 이상의 조어 요소밤낮, 꽃집, 풋사과, 지우개

‘먹다’는 ‘먹- + -다’로 형태소 분석이 가능하지만 단어 형성에서는 어미 ‘-다’를 조어 요소로 세지 않기 때문에 단일어입니다. 반면 ‘풋사과’는 접두사 ‘풋-’이 ‘사과’에 붙어 새 단어를 만들었으므로 복합어입니다.

3. 복합어는 합성어와 파생어로 나뉜다

합성어둘 이상의 어근이 결합합니다.
밤 + 낮 → 밤낮
꽃 + 집 → 꽃집
파생어어근이나 단어에 접사가 붙습니다.
풋- + 사과 → 풋사과
지우- + -개 → 지우개

국립국어원 온라인가나다도 ‘대나무·돛단배·갈대’를 실질 형태소끼리 결합한 합성어(복합어)로, ‘소화기·주님·수산물·기행문’을 어근에 접미사가 붙은 파생어(복합어)로 설명합니다.

4. 합성어 — 둘 이상의 어근이 결합해 하나의 단어가 된다

합성어는 실질적 의미를 지닌 어근들이 결합해 하나의 단어를 이루는 경우입니다. ‘밤낮’은 ‘밤’과 ‘낮’, ‘꽃집’은 ‘꽃’과 ‘집’이 결합합니다.

어근 + 어근 → 합성어

합성어의 세부 분류에서는 통사적 합성어와 비통사적 합성어를 나누기도 합니다. 다만 복합어를 처음 판별하는 단계에서는 우선 접사가 아니라 둘 이상의 어근이 결합했는가를 확인하면 됩니다.

5. 파생어 — 어근이나 단어에 접사가 붙어 새 단어가 된다

파생어는 접두사나 접미사가 단어 형성에 참여합니다. ‘풋사과’에서는 ‘풋-’이 접두사이고 ‘사과’가 어근입니다. ‘지우개’에서는 ‘지우-’가 어근이고 ‘-개’가 접미사입니다.

접사 + 어근 → 파생어　/　어근 + 접사 → 파생어

접사가 붙었다고 반드시 품사가 바뀌는 것은 아닙니다. 접사는 뜻을 더하거나 제한할 수도 있고, 어떤 경우에는 품사를 바꾸기도 합니다. 복합어 판별에서는 우선 접사가 단어 형성에 참여했는가를 확인합니다.

6. 형태소가 둘이면 모두 복합어인가 — 아니다

‘먹다’, ‘간다’, ‘부른다’처럼 활용형을 보면 형태소가 둘 이상으로 나뉩니다. 하지만 이런 말의 어미는 새 단어를 만드는 접사가 아니라 활용을 나타내는 요소입니다.

형태형태소 분석단어 형성 판정
먹다먹- + -다단일어
부른다부르- + -ㄴ다기본 단어 ‘부르다’는 단일어
풋사과풋- + 사과파생어 → 복합어
밤낮밤 + 낮합성어 → 복합어
‘형태소 수 = 복합어 여부’가 아닙니다.
형태소 분석은 최소 단위를 찾는 작업이고, 단어 형성 분석은 어떤 요소가 새 단어를 만들었는지 보는 작업입니다.

7. 어미는 왜 조어 요소에서 제외하는가 — 활용과 단어 형성은 다른 층위다

어미는 같은 용언이 문장 안에서 시제, 종결, 연결, 높임 등의 문법 기능을 나타내도록 형태를 바꾸는 요소입니다. ‘먹다, 먹고, 먹으니’가 서로 다른 새 단어가 되는 것이 아니라 ‘먹다’라는 하나의 단어가 활용한 결과인 것처럼 말입니다.

단어 형성풋- + 사과 → 풋사과
새 단어가 만들어짐
활용먹- + -고 → 먹고
같은 단어의 활용형

그래서 단일어와 복합어를 가를 때는 일반적으로 어미를 조어 요소에서 제외합니다.

8. 복합어와 구를 구별하는 기준 — 붙어 있다고 모두 하나의 단어는 아니다

둘 이상의 단어가 연속해서 나타난다고 모두 합성어가 되는 것은 아닙니다. 각각이 독립적인 단어로 문장 안에서 결합한 구일 수도 있습니다.

예를 들어 기존 원문은 ‘우리말·우리나라’와 ‘우리 집·우리 마을’을 비교해, 하나의 단어로 굳어진 경우와 각각의 독립 단어가 결합한 경우의 차이를 보여 줍니다.

구별 질문
“이 결합이 사전에 하나의 단어로 굳어 있는가?”, “각 요소 사이에 다른 말을 자유롭게 끼울 수 있는가?”, “하나의 단어처럼 통째로 쓰이는가?”를 함께 봅니다.

9. 사전의 붙임표는 어떻게 활용하는가 — 구성 성분을 보는 힌트

국립국어원은 표준국어대사전과 우리말샘에서 많은 복합어의 구성 성분을 붙임표로 표시한다고 설명합니다. 예를 들어 ‘지우-개’처럼 표시되면 ‘-개’를 사전에서 접사로 확인하여 파생어임을 판단할 수 있고, ‘꽃-집’처럼 두 성분이 모두 일반 명사라면 합성어로 판단하는 데 도움이 됩니다.

다만 붙임표가 절대적인 판정표는 아닙니다.
음절 단위로 구성 성분이 잘 드러나지 않는 복합어도 있고, 동일한 단어를 학자에 따라 다르게 분석하는 경우도 있습니다.

10. 한자어와 경계 사례 — 모든 단어를 기계적으로 자르지 않는다

한자어는 각 한자가 뜻을 지닌다고 해서 곧바로 한 글자씩 어근으로 세어 합성어라고 할 수 없습니다. 국립국어원은 ‘화장’ 같은 2음절 한자어의 단어 형성은 문법 견해에 따라 해석이 달라질 수 있다고 안내합니다.

따라서 시험이나 학교 문법에서 분석이 갈릴 수 있는 단어는 교과서의 체계와 사전의 정보를 우선합니다. 명확한 예를 통해 판별 원리를 익힌 뒤 경계 사례를 별도로 다루는 편이 안전합니다.

11. 다단계 형성 — 복합어 안에 이미 만들어진 복합어가 들어갈 수 있다

단어 형성은 한 번의 결합으로 끝나지 않을 수 있습니다. 예를 들어 ‘웃음꽃’은 먼저 ‘웃- + -음 → 웃음’이라는 파생이 일어나고, 그 뒤 ‘웃음 + 꽃 → 웃음꽃’이라는 합성이 일어납니다.

웃- + -음 → 웃음(파생) → 웃음 + 꽃 → 웃음꽃(합성)

따라서 형태소가 셋 이상인 복잡한 단어는 모두 한꺼번에 나열하기보다 가장 마지막에 결합한 직접 구성 요소부터 단계적으로 보는 것이 좋습니다.

12. 실전에서 복합어를 판별하는 네 단계

1어미 제외용언이면 활용 어미를 먼저 조어 판별에서 제외합니다.
2접사 확인접두사·접미사가 새 단어를 만들었는지 봅니다.
3어근 수 확인둘 이상의 어근이 결합했는지 확인합니다.
4최종 분류접사가 있으면 파생어, 둘 이상의 어근이면 합성어, 둘 다 복합어입니다.
  • 복합어는 합성어와 파생어를 아우르는 상위 개념입니다.
  • 합성어는 둘 이상의 어근이 결합합니다.
  • 파생어는 어근이나 단어에 접사가 결합합니다.
  • 형태소가 둘 이상이라고 무조건 복합어는 아닙니다.
  • 활용 어미는 일반적으로 단어 형성 판별에서 제외합니다.
  • 복합어와 구는 단어로 굳어 있는지까지 확인합니다.
  • 사전의 붙임표는 구성 성분을 보는 중요한 힌트입니다.
  • 경계 사례는 교과서와 사전의 분석을 우선합니다.

13. 한눈에 정리 — 복합어는 ‘둘 이상이 결합해 새 단어를 만든 구조’다

구분구조예
단일어하나의 어근산, 하늘, 먹다
합성어어근 + 어근밤낮, 꽃집
파생어어근 + 접사 / 접사 + 어근지우개, 풋사과
복합어합성어와 파생어를 아우름밤낮, 꽃집, 지우개, 풋사과
복합어를 판별할 때는 형태소 개수보다 ‘무엇이 새 단어를 만들었는가’를 먼저 봅니다.
접사가 붙었으면 파생어, 둘 이상의 어근이 결합했으면 합성어이며 둘은 모두 복합어입니다.
