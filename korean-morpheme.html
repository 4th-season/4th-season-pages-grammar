형태소란 무엇인가 — 뜻을 가진 최소 단위와 분류 기준

형태소는 뜻을 가진 가장 작은 말의 단위입니다. 단어보다 작을 수도 있고 단어 하나가 형태소 하나일 수도 있습니다. 핵심은 눈에 보이는 글자 수가 아니라, 더 나누었을 때 의미나 문법 기능이 유지되는지입니다.

1. 형태소 — 뜻을 가진 가장 작은 말의 단위

표준국어대사전은 형태소를 “뜻을 가진 가장 작은 말의 단위”로 풀이합니다. 여기서 ‘가장 작다’는 것은 단순히 글자 수가 짧다는 뜻이 아닙니다. 어떤 말을 더 잘게 나누었을 때 각각의 조각이 더 이상 독립된 의미나 문법 기능을 갖지 못한다면, 그 지점이 형태소의 경계가 됩니다.

형태소 = 뜻이나 문법 기능을 유지하는 최소 단위
형태소를 찾는 질문은 하나입니다.
“이 부분을 더 나누어도 각 조각에 의미나 문법 기능이 남는가?” 남지 않는다면 그 단위는 더 이상 형태소 내부로 쪼개지지 않습니다.

예를 들어 ‘자는’은 ‘자-’와 ‘-는’으로 나눌 수 있습니다. ‘자-’는 ‘잠을 자다’라는 실질 의미를 갖고, ‘-는’은 뒤의 명사를 꾸미는 관형사형 기능을 나타냅니다. 따라서 둘은 각각 하나의 형태소입니다.

2. ‘뜻’에는 사전적 의미뿐 아니라 문법적 의미도 포함된다

형태소를 처음 배울 때 가장 흔한 오해는 “뜻이 있어야 한다면 조사나 어미는 형태소가 아닌 것 아닌가?”라는 생각입니다. 하지만 형태소에서 말하는 뜻은 사물·행동·성질 같은 실질적 의미만을 가리키지 않습니다. 시제, 높임, 문장 종결, 관계 표시 같은 문법적 의미와 기능도 포함됩니다.

먹-‘음식을 먹다’라는 실질 의미가 있습니다.
-었-과거 시제를 나타내는 문법적 의미가 있습니다.
-다문장을 종결하는 문법 기능을 가집니다.
-이/가, -을/를명사와 다른 성분의 문법 관계를 표시합니다.
‘뜻’보다 ‘기능’까지 함께 보십시오.
형태소 분석에서는 어미·조사·접사처럼 사전적인 내용 뜻이 약한 요소도 문법적 의미나 관계 기능을 가지면 하나의 형태소로 봅니다.

3. 글자·음절과 형태소는 같은 단위가 아니다

글자나 음절은 소리와 표기의 단위이고, 형태소는 의미의 단위입니다. 그래서 글자 하나가 형태소 하나가 될 수도 있고, 여러 음절이 모여 형태소 하나가 될 수도 있습니다.

표현겉모양형태소 분석핵심
집1음절집단어 하나이자 형태소 하나
사람2음절사람두 음절이지만 더 나눌 의미 단위가 없음
먹었다3음절먹- / -었- / -다음절 경계와 형태소 경계가 일치하지 않음
아끼셨다4음절아끼- / -시- / -었- / -다한 음절 ‘셨’ 안에도 두 형태소가 결합
음절 수를 세어 형태소 수를 정하면 안 됩니다.
‘셨’은 한 음절이지만 주체 높임 ‘-시-’와 과거 시제 ‘-었-’이 결합한 형태로 분석됩니다. 형태소 경계는 표면의 음절 경계보다 더 깊은 문법 구조를 봅니다.

4. 단어와 형태소 — 둘은 층위가 다르다

단어는 문장에서 쓰이는 기본 문법 단위이고, 형태소는 그 단어를 더 잘게 나눈 최소 의미 단위입니다. 단어 하나가 형태소 하나일 수도 있지만, 여러 형태소가 결합해 단어 하나를 만들 수도 있습니다.

형태소→형태소들의 결합→단어→문장 속 사용
집단어 1개 / 형태소 1개
먹히다단어 1개 / 형태소 3개: 먹- / -히- / -다

따라서 “단어를 형태소로 나눈다”는 표현은 맞지만, 모든 단어가 반드시 둘 이상의 형태소로 이루어진 것은 아닙니다. ‘사람’, ‘집’, ‘책’처럼 더 나누기 어려운 단일 형태소 단어도 있습니다.

5. 먹히다 — 어근, 접사, 어미를 형태소로 분리한다

국립국어원은 ‘먹히다’를 먹- / -히- / -다로 형태소 분석합니다. 이 예는 형태소의 실질 의미와 문법 기능이 어떻게 함께 작동하는지 보여 줍니다.

형태소기능분류 관점
먹-‘먹다’의 핵심 의미실질 의미를 가진 형태소
-히-피동의 뜻을 더하는 접사문법 기능을 가진 의존 형태소
-다용언의 기본형을 만드는 종결 어미문법 기능을 가진 의존 형태소
어간 전체가 언제나 형태소 하나인 것은 아닙니다.
‘먹히-’는 활용할 때 변하지 않는 어간이지만, 형태소 분석에서는 ‘먹-’과 피동 접사 ‘-히-’로 더 나뉩니다. 어간과 형태소는 서로 다른 분석 기준입니다.

6. 어미도 형태소다 — 문법적 의미가 남아 있기 때문이다

‘먹었다’를 보면 ‘먹- / -었- / -다’로 나눌 수 있습니다. ‘-었-’은 과거 시제를 나타내고, ‘-다’는 문장 종결 기능을 가집니다. 둘 다 실질 사물을 가리키지는 않지만 문법 의미가 분명하므로 형태소입니다.

‘아끼셨다’도 마찬가지입니다. 표면상 ‘셨’은 한 음절이지만, 형태소 분석에서는 주체 높임 ‘-시-’와 과거 시제 ‘-었-’이 결합한 것으로 봅니다.

아끼셨다 → 아끼- + -시- + -었- + -다
표면형과 형태소형을 구분하십시오.
형태소 분석은 지금 눈에 보이는 글자 모양을 그대로 자르는 작업이 아니라, 그 안에 어떤 문법 요소가 결합해 있는지를 복원하는 작업입니다.

7. 직접 구성 성분 분석과 형태소 분석은 같은 것이 아니다

복합어를 분석할 때는 ‘형태소 분석’과 ‘직접 구성 성분 분석’을 구분해야 합니다. 국립국어원은 ‘달맞이’를 직접 구성 성분으로는 달 / 맞이로 나눌 수 있지만, 형태소 단위로는 달- / 맞- / -이처럼 더 세분할 수 있다고 설명합니다.

직접 구성 성분복합어를 직접 이루는 큰 두 덩어리를 찾습니다. 예: 달 / 맞이
형태소 분석더 이상 의미나 문법 기능을 유지하며 나눌 수 없는 최소 단위까지 내려갑니다. 예: 달- / 맞- / -이
분석의 목적이 다릅니다.
직접 구성 성분 분석은 ‘이 단어가 어떻게 만들어졌는가’를 크게 보고, 형태소 분석은 ‘어떤 최소 의미 단위가 들어 있는가’를 끝까지 확인합니다.

8. 형태소 분석은 왜 가끔 답이 달라지는가

모든 형태소 분석이 항상 하나의 절대적인 답으로만 정리되는 것은 아닙니다. 축약된 형태, 역사적으로 굳어진 말, 복합어의 구조 등에서는 문법 이론이나 교과서 체계에 따라 분석 방식이 달라질 수 있습니다.

국립국어원 온라인가나다도 형태소 분석에는 문법적 견해 차이가 있을 수 있으며 학생이라면 교과서의 견해를 따르는 것이 안전하다고 여러 차례 안내합니다.

‘사전 분석’과 ‘학교 문법 분석’이 다르면 교과서 기준을 우선하십시오.
시험 문제는 해당 교육과정과 교과서의 분석 체계를 전제로 출제됩니다. 국립국어원 설명은 기본 원리를 확인하는 근거로 활용하되, 수업에서 정한 분류 체계가 있으면 그것을 우선해야 합니다.

9. 형태소를 찾는 가장 안전한 순서

1단어의 기본 의미 찾기핵심 뜻을 가진 부분을 먼저 찾습니다.
2문법 기능 찾기시제·높임·종결·관계 표시 요소가 붙었는지 봅니다.
3더 나눌 수 있는지 확인나눈 각 부분에 의미나 기능이 남는지 확인합니다.
4표면형 복원‘셨’처럼 줄어든 형태라면 원래 결합한 형태를 복원합니다.
  • 글자 수나 음절 수만 보고 형태소 수를 정하지 않습니다.
  • 실질 의미뿐 아니라 시제·높임·종결 같은 문법적 의미도 봅니다.
  • 어간 전체가 형태소 하나인지, 접사까지 포함한 복합 어간인지 다시 확인합니다.
  • 단어 형성 분석과 형태소 분석을 혼동하지 않습니다.
  • 분석이 갈리는 경우에는 교과서와 수업의 기준을 우선합니다.

10. 한눈에 정리 — 형태소는 ‘최소 의미 단위’다

구분핵심예
형태소뜻이나 문법 기능을 가진 가장 작은 말의 단위먹-, -었-, -다
음절한 번에 소리 낼 수 있는 소리 단위먹 / 었 / 다
단어문장에서 쓰이는 기본 문법 단위먹었다
직접 구성 성분복합어를 직접 이루는 큰 성분달 / 맞이
형태소 분석최소 의미 단위까지 세분달- / 맞- / -이
형태소를 찾는 핵심은 “더 나눌 수 있는가”가 아니라 “더 나누어도 의미나 문법 기능이 남는가”입니다.
이 기준을 잡으면 글자·음절·단어와 형태소를 구분하고, 이후 자립/의존 형태소·실질/형식 형태소 분석까지 자연스럽게 이어갈 수 있습니다.
