언어 단위의 위계 — 작은 단위가 큰 단위를 만드는 방식

언어 단위의 위계를 알면 기출문제가 다르게 보입니다

‘형태소 → 단어 → 구 → 절 → 문장’이라는 순서를 외워도, 복잡한 문장에 들어가면 어디서 끊어야 할지 막힐 수 있습니다. 위계는 단어 수를 세는 표가 아니라, 무엇이 무엇을 직접 이루는가를 판정하는 방법이기 때문입니다.

“언니가 읽던 책이 여기 있다.”

전체 문장의 주어는 무엇일까요? 언니가만 보아서는 안 됩니다. 언니가 읽던 것이 책이라는 관계를 먼저 잡으면, 전체의 주어 덩어리는 언니가 읽던 책이가 됩니다.

이번 글의 역할 상위 글인 언어 단위가 음운·음절·담화까지 전체 지도를 보여 준다면, 이 글은 형태소·단어·구·절·문장의 직접 구성·포함·병렬 관계를 실제 문제에서 판정합니다.

1. 작은 단위가 큰 단위를 이루는 방식에는 조건이 있습니다

한 단위가 더 큰 단위 속에 들어 있다고 해서 곧바로 직접 구성 요소인 것은 아닙니다. 직접 구성 요소는 한 층위 위의 전체를 바로 이루는 부분입니다. 단어를 여러 형태소로 나누거나 문장을 여러 어절로 나누는 작업과, 어떤 두 덩어리가 바로 결합하는지 밝히는 작업은 다릅니다.

관찰할 관계판정 질문사례
구성바로 상위 구조를 이루는 두 요소는 무엇인가?‘민물고기’ → ‘민물’ + ‘고기’
포함더 큰 문장 속에 작은 주어·서술어 구조가 들어 있는가?‘언니가 읽던’은 ‘책’을 꾸미는 관형절
기능이 큰 덩어리는 전체 문장 속에서 무슨 역할을 하는가?‘언니가 읽던 책이’는 전체 문장의 주어
병렬둘 이상의 요소가 대등하게 연결될 자격이 있는가?‘물과 불’, ‘밖은 춥고 안은 덥다’

2. 형태소에서 단어로 — 내부 구성과 단어 종류는 다릅니다

먹었다 = 먹- + -었- + -다

‘먹었다’는 학교 문법에서 한 단어의 활용형이지만, 안으로는 어간과 어미라는 여러 형태소로 분석됩니다. 분리할 수 있다는 사실과 띄어 써야 한다는 판단은 다른 문제입니다.

‘학생들’은 학생 + -들로 설명할 수 있고, ‘학생들이’처럼 조사가 결합하면 조사를 별도 단어로 다루는 학교 문법의 분류가 적용됩니다. 형태소의 개수·단어의 개수·어절의 개수를 한 번에 답하려 하지 말아야 합니다.

주의 조사는 학교 문법에서 단어로 처리하지만 어미는 용언의 활용형 내부에 놓입니다. 단어 형성의 어근·접사와 활용의 어간·어미도 서로 다른 분석 질문입니다.

3. 직접 구성 요소는 한 번에 끝까지 쪼개는 분석이 아닙니다

민물고기를 보겠습니다. 이 낱말은 ‘민물’과 ‘고기’가 결합한 합성어입니다. 다시 ‘민물’을 분석하면 ‘민-’과 ‘물’이 나타날 수 있습니다. 어느 단계에서 묻느냐에 따라 직접 구성 요소가 달라집니다.

민물고기 ├─ 민물 │ ├─ 민- (접두사) │ └─ 물 └─ 고기

여기서 전체 ‘민물고기’의 직접 구성 요소는 민물 / 고기입니다. 속에 접사가 하나 있다고 해서 전체 단어를 곧장 파생어로 판정하지 않습니다. 최상위 분기에서 어떤 결합이 이루어졌는지를 확인해야 합니다.

분석 후보를 세운 뒤에는 ① 분리한 말이 실제로 존재하는지, ② 분리 전후의 의미 관계가 자연스러운지 함께 확인합니다.

4. 단어와 어절 — 숫자가 달라지는 이유

학생이 새 책을 읽었다.
분석 단위결과판단 기준
어절학생이 / 새 / 책을 / 읽었다 → 4어절띄어 쓴 말의 덩어리
단어학생 / 이 / 새 / 책 / 을 / 읽었다 → 6단어조사는 단어, 어미는 단어로 따로 세지 않음
문장 성분학생이(주어) · 새(관형어) · 책을(목적어) · 읽었다(서술어)문장 안에서 맡은 역할

‘새’는 품사로는 관형사이면서, 문장 안에서는 관형어입니다. 같은 표현이라도 분석의 관점을 바꾸면 다른 답이 나옵니다. 이를 모순으로 판단해서는 안 됩니다.

5. 구와 절은 길이가 아니라 주어·서술어 관계로 가릅니다

표현분석핵심 근거
아주 예쁜 꽃구그 전체에 독립된 주어·서술어 관계가 중심이 아님
꽃이 피는절‘꽃이’(주어)와 ‘피는’(서술어)의 관계가 있음
내가 읽던절‘내가’가 ‘읽던’의 주어로 연결됨

절에는 문맥에 따라 주어가 드러나지 않는 경우도 있으므로 겉으로 보이는 조사 하나만으로 기계적으로 판단하면 안 됩니다. 어떤 용언이 어떤 주체의 행위를 나타내는지 문장 내부의 관계를 확인해야 합니다.

6. 절이 더 큰 문장 안에 들어갈 때, 전체 주어는 달라집니다

언니가 찾던 책이 여기 있구나.
[문장] ├─ [주어] [[관형절 언니가 찾던] 책이] └─ [서술부] 여기 있구나

‘언니가’는 관형절 내부의 주어이며, 전체 문장의 주어를 그 자리에서 바로 끊어 ‘언니가’로 정하면 잘못된 위계가 됩니다. 큰 구조를 먼저 구분하고 안쪽으로 내려가는 방식이 필요합니다.

이는 뒤에서 볼 2017학년도 9월 12번의 기본 원리이기도 합니다.

7. 포함 관계와 문장 성분의 역할을 구별합니다

‘새 책을’은 내부적으로 ‘새/책/을’로 분해할 수 있지만, 전체 문장에서는 하나의 목적어 덩어리가 될 수 있습니다. 내부 구성 요소의 수와 외부 기능의 수는 같은 값일 필요가 없습니다.

문제에서 직접 구성 요소를 요구하면 구성의 첫 분기를, 문장 성분을 요구하면 서술어와의 관계를, 품사를 요구하면 단어별 특성을 우선합니다.

8. 병렬 구성은 같은 자격의 요소가 대등하게 결합합니다

① 물과 불　② 밖은 춥고 안은 덥다.

①은 두 명사가 조사로 연결된 병렬 구성입니다. ②는 두 절이 연결 어미로 대등하게 연결됩니다. 두 경우 모두 ‘무엇과 무엇이 연결되는가’를 먼저 식별해야 합니다.

2026학년도 9월 모의평가 지문은 단어·구·절의 단위가 같은지, 선행절·후행절에서 생략된 성분의 기능이 같은지, 병렬된 각 항목이 같은 서술어와 호응하는지를 판단하도록 설명합니다. 다만 해당 지문은 명사와 명사구도 병렬 가능하다는 조건을 제시하므로 무조건 ‘단위가 다르면 불가’라고 암기해서는 안 됩니다.

9. 기출 ① 2004학년도 수능 36번 — 선택과 통합의 층위를 구별

E2004-CSAT-Q36 · 개념 연계

구조·선택·통합을 같은 뜻으로 쓰지 않기

언어 체계 설명문이 제시한 핵심은 대체 가능한 항목의 선택 관계와 동시에 연결되어 구조를 만드는 통합 관계의 구별입니다. 문제는 이어진 글 속의 문장과 단어를 가리키며 두 관계를 판정하게 합니다.

  1. 표시된 대상이 단어인지 문장인지, 혹은 글 전체인지 확인합니다.
  2. 그 자리에 다른 표현을 바꾸어 넣는 관계인지 살펴봅니다.
  3. 요소들이 이어져 더 큰 구조를 함께 이루는 관계인지 따로 검토합니다.
  4. 선지에서 서로 다른 층위를 같은 종류의 관계로 오인하지 않았는지 판정합니다.

이 글은 원천 DB의 발문과 선지 구조를 토대로 판단 절차를 설명합니다. 공식 정답 번호는 별도 대조 후 확정합니다.

10. 기출 ② 2017학년도 9월 12번 — 전체 주어를 어떻게 찾는가

E2017-SEP-Q012 · 정답 ② 검증

최상위 직접 구성 요소부터 나누기

이 문항은 직접 구성 요소 분석을 바탕으로 다섯 문장의 잘못된 구분을 찾는 문제입니다. ②의 핵심은 ‘소포가 도착했다고 들었다’를 전체 주어 ‘소포가’와 서술부 ‘도착했다고 들었다’로 자를 수 있는지입니다.

‘소포가’는 ‘소포가 도착했다’에 해당하는 안긴 내용의 주어입니다. 전체 문장의 바로 위 구조를 ‘소포가’와 나머지 서술부로 분석할 수는 없습니다. 발문이 요구한 것은 안쪽에 들어 있는 주어를 찾아내는 일이 아니라 전체 구조의 첫 분기입니다.

  1. 문장 전체에 먼저 결합한 덩어리가 있는지 찾습니다.
  2. 안긴절 속 주어와 문장 전체의 주어를 구별합니다.
  3. 각 선지가 제시한 첫 분기가 실제 최상위 직접 구성 요소인지 판정합니다.

수능 DB 기록 정답은 ②이고, 별도 공개 정답표에서도 ②를 확인했습니다.

11. 기출 ③ 2026학년도 9월 35번 — 병렬인지 아닌지 판단

E2026-SEP-Q035 · 병렬 구성

단어 순서를 바꾸었다고 병렬이 되는 것은 아닙니다

이 문제는 병렬 구성의 대등성을 판단하게 합니다. 예를 들어 ‘도서관이 우리 집과 가깝다’와 ‘우리 집이 도서관과 가깝다’의 의미가 유사하더라도, 그 자체로 두 문장에 병렬 구성이 있다고 단정할 수는 없습니다. 두 성분이 문장 안에서 접속되어 대등하게 결합했는지를 봐야 합니다.

반면 ‘팥, 콩, 쌀이 많다’처럼 조사가 없어도 나열에 의해 병렬 관계가 성립할 수 있습니다. 핵심은 연결 어미의 존재만이 아니라 문장 안에서 어떤 요소들이 동등한 기능으로 병치되는가입니다.

  1. 병렬로 연결됐다고 주장하는 두 요소를 표시합니다.
  2. 둘의 문법 단위와 문장 속 기능을 확인합니다.
  3. 대등성·나열·접속 방식과 지문에서 제시한 조건을 대조합니다.

12. 기출 ④ 2026학년도 9월 36번 — 잘못된 병렬을 세 이유로 분류

E2026-SEP-Q036 · 병렬·생략·호응

㉠ 단위 / ㉡ 생략 / ㉢ 호응의 순서

문항은 다섯 표현을 비교해 부적절한 이유가 무엇인지 판단하게 합니다. 예시에서 명사구인 ‘체력 단련’과 절인 ‘방을 청소한’처럼 병렬된 요소들의 단위가 달라지는 경우가 있습니다. 또 ‘국이나 빵을 굽는다’처럼 각 병렬 요소가 동일한 서술어 ‘굽다’와 자연스럽게 호응하는지도 따져야 합니다.

지문 기준질문검사 순서
㉠ 병렬 단위병렬된 말의 단위는 같은가? 예외 조건이 있는가?구성 요소의 층위 확인
㉡ 생략생략된 성분이 선행절과 같은 문장 성분인가?실제 복원 후 비교
㉢ 호응나열된 항목 모두가 서술어에 적절히 호응하는가?각 항목을 서술어와 개별 결합

선지 정오를 예단하기보다, 각 문장을 단위 → 성분 → 의미 호응 순서로 다시 분석하는 것이 재현 가능한 풀이법입니다. 이 문항의 문장별 오류 조합과 정답번호는 정답·해설 원문과 대조해 개별 문항 분석 글에서 확정합니다.

13. 처음 보는 문장도 같은 순서로 분석합니다

  1. 발문에서 묻는 분석 층위를 정합니다. 개수인가, 직접 구성 요소인가, 병렬 조건인가?
  2. 최상위 덩어리부터 묶습니다. 문장이면 안긴절을 포함해 큰 구조를 먼저 봅니다.
  3. 필요한 층위에서만 바로 아래 단계로 나눕니다. 무조건 음운까지 쪼개지 않습니다.
  4. 구조와 기능을 분리합니다. 내부 구성을 확인한 뒤 문장 속 역할을 봅니다.
  5. 병렬이라면 단위·대등성·생략·호응 조건을 따로 검증합니다.
  6. 선지의 주장을 원문에 대입하고 근거가 없는 추측을 버립니다.

14. 흔한 오개념을 이렇게 고칩니다

잘못된 판단바른 판별 기준
음절 수와 형태소 수는 같다음절은 소리 단위, 형태소는 의미·기능 단위이다
띄어 쓴 덩어리 하나는 단어 하나다조사가 들어간 어절은 둘 이상의 단어일 수 있다
문장에 주어가 보이면 그것이 전체의 주어다안긴절 내부의 주어와 전체 문장의 주어를 구별한다
접속 조사가 없으면 병렬 구성도 없다조사 없이 나열한 구성도 병렬이 될 수 있다
같은 글의 문장들이면 모두 같은 층위다단어·절·문장·담화는 다른 분석 단위이다

15. 다음 개념글은 무엇을 읽어야 할까요?

언어 단위 총론에서 여러 층위의 전체 지도를 본 뒤, 문항에서 요구한 지식에 따라 필요한 글로 이동합니다.

형태·기능·의미같은 형태를 다른 관점으로 분류하는 기준 품사와 문장 성분단어의 종류와 문장 속 역할의 차이 규칙과 체계선택 관계와 통합 관계로 구조를 읽는 법 문법 분석 방법발문에서 필요한 개념부터 찾는 순서

기출 전체를 외우기보다 한 문항에서 배운 판단 기준을 다른 문제에도 적용할 수 있는지가 중요합니다.
