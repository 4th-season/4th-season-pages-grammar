합성어란 무엇인가 — 둘 이상의 어근이 결합한 단어

합성어는 둘 이상의 실질 형태소, 곧 어근이 결합하여 하나의 단어가 된 말입니다. 핵심은 글자 수가 아니라 어근의 결합이며, 접사가 결합한 파생어와 구별해야 합니다.

1. 합성어의 정확한 뜻 — 둘 이상의 실질 형태소가 결합한 단어

합성어는 단어 형성에서 가장 중요한 두 갈래 중 하나입니다. 표준국어대사전의 설명에 따르면 합성어는 둘 이상의 실질 형태소가 결합하여 하나의 단어가 된 말입니다. 학교 문법에서는 이를 보통 ‘둘 이상의 어근이 결합한 단어’라고 정리합니다.

어근 + 어근 → 합성어

따라서 ‘밤낮’에서 밤과 낮, ‘돌다리’에서 돌과 다리처럼 각각 독립적인 실질 의미를 가진 요소들이 하나의 단어를 만들면 합성어가 됩니다.

핵심 기준
합성어는 접사가 아니라 둘 이상의 어근이 결합해 만들어집니다.

2. ‘어근이 둘 이상’이라는 뜻 — 글자 수나 음절 수가 아니다

합성어를 판별할 때 글자 수는 기준이 아닙니다. ‘밤낮’은 두 음절이지만 합성어이고, ‘하늘’은 두 음절이지만 단일어입니다. 차이는 음절 수가 아니라 단어 안에 몇 개의 어근이 참여했는가에 있습니다.

단어분석판정
하늘하나의 어근단일어
밤낮밤 + 낮합성어
꽃집꽃 + 집합성어
풋사과풋- + 사과파생어

3. 밤낮·꽃집·돌다리 — 전형적인 합성어를 먼저 익힌다

합성어 판별을 익힐 때는 논쟁의 여지가 적은 전형적인 예부터 보는 것이 좋습니다.

밤낮밤 + 낮
두 명사 어근이 결합합니다.
꽃집꽃 + 집
두 명사 어근이 결합합니다.
돌다리돌 + 다리
두 실질 형태소가 결합합니다.
덮밥덮- + 밥
용언 어간에서 온 어근과 명사 어근이 결합합니다.

국립국어원 온라인가나다는 ‘덮밥’을 단어 형성 차원에서 합성어로 설명하며, ‘덮-’과 ‘밥’을 각각 어근으로 볼 수 있다고 안내합니다.

4. 합성어와 파생어의 차이 — 두 번째 요소가 어근인가 접사인가

합성어와 파생어는 모두 복합어이지만 형성 방식이 다릅니다. 합성어는 둘 이상의 어근이 결합하고, 파생어는 어근이나 단어에 접사가 붙습니다.

구분형성 구조예
합성어어근 + 어근밤낮, 꽃집, 돌다리
파생어접사 + 어근 / 어근 + 접사풋사과, 지우개

겉모양이 비슷하다고 바로 합성어로 보면 안 됩니다. 국립국어원은 ‘맞먹다’에서 ‘맞-’을 접두사로 보고, ‘맞- + 먹- + -다’의 파생어로 설명합니다. 즉 앞부분이 실질 의미를 가진 어근인지, 사전에서 접사로 처리되는지 확인해야 합니다.

5. 합성어와 단일어의 차이 — 하나의 어근인가, 둘 이상의 어근인가

단일어하나의 어근으로 이루어짐
산, 하늘, 먹다
합성어둘 이상의 어근이 결합함
밤낮, 꽃집, 돌다리

여기서도 활용 어미는 조어 요소로 세지 않습니다. ‘먹다’는 먹-과 -다로 형태소 분석이 되지만, 단어 형성 관점에서는 하나의 어근을 가진 단일어입니다.

6. 어근과 어간을 섞지 않는 법 — 단어 형성과 활용의 관점이 다르다

국립국어원은 ‘힘들다’를 설명하면서 단어 형성 관점에서는 ‘힘’과 ‘들-’이 각각 어근이고, 활용 관점에서는 ‘힘들-’ 전체가 어간이라고 설명합니다. 같은 단어 안에서도 분석 목적이 다르면 사용하는 용어가 달라집니다.

단어 형성: 힘 + 들- → 합성어
활용: 힘들- + -다 → 어간 + 어미
어근과 어간은 같은 층위의 개념이 아닙니다.
합성어 판별에서는 어근의 결합을 보고, 활용에서는 어간과 어미를 봅니다.

7. 합성어와 구의 경계 — 붙어 있거나 자주 쓰인다고 모두 합성어는 아니다

둘 이상의 단어가 함께 쓰인다고 자동으로 합성어가 되는 것은 아닙니다. 각각의 단어가 문장 안에서 결합한 명사구나 구일 수도 있습니다.

국립국어원은 ‘미세 플라스틱’, ‘환경 오염’을 일반적으로 두 개의 명사로 이루어진 명사구로 보고 합성어로 보지 않는다고 안내한 바 있습니다. 다만 전문 용어나 새말의 조어 분석은 견해차가 생길 수 있습니다.

확인 질문
① 사전에 하나의 단어로 올라 있는가? ② 두 요소가 통째로 하나의 개념을 가리키는가? ③ 각 요소가 자유롭게 분리·수식되는 구인지 확인합니다.

8. 직접 구성 요소로 보는 방법 — 마지막 결합이 무엇인지 찾는다

복잡한 합성어는 형태소를 한꺼번에 나열하기보다 마지막에 직접 결합한 두 부분을 찾는 것이 좋습니다. 이를 직접 구성 요소 분석이라고 생각하면 됩니다.

큰 단어 → 마지막에 결합한 두 덩어리 → 각 덩어리를 다시 분석

예를 들어 ‘물놀이’처럼 여러 요소가 들어 있는 단어는 사전에서 제시하는 최종 경계를 확인해야 합니다. 국립국어원은 표준국어대사전의 최종 형태 경계가 ‘물-놀이’로 제시된다는 점을 근거로 합성어로 볼 수 있다고 설명합니다.

9. 합성어가 여러 단계로 만들어질 때 — 먼저 만들어진 단어가 다시 결합할 수 있다

합성어 내부에는 이미 파생이나 합성을 거친 요소가 들어갈 수 있습니다. 그래서 최종 분류를 할 때는 각 형태소의 목록만 보는 것이 아니라, 마지막 형성 단계를 확인해야 합니다.

복잡한 단어는 계층적으로 봅니다.
‘무엇 + 무엇이 마지막에 결합했는가’를 먼저 찾고, 필요하면 그 안의 구성 요소를 다시 나눕니다.

10. 통사적 합성어와 비통사적 합성어 — 다음 단계에서 보는 두 유형

합성어는 다시 통사적 합성어와 비통사적 합성어로 나눌 수 있습니다. 통사적 합성어는 일반적인 문장 구성 방식과 비슷한 결합을 보이고, 비통사적 합성어는 일반적인 통사 규칙과 다른 결합을 보입니다.

예를 들어 국립국어원은 ‘신나다’를 ‘신이 나다’로 환언할 수 있다는 점에서 통사적 합성어로 볼 수 있다고 설명합니다. 다만 이러한 세부 분류는 문법 이론이나 교과서에 따라 견해차가 생길 수 있으므로 다음 글에서 각각 따로 다룹니다.

통사적 합성어 → 비통사적 합성어 → 복합어 전체 보기 →

11. 분석이 갈리는 경우 — 사전과 교과서 기준을 우선한다

조어 분석은 모든 단어에서 하나의 견해로 고정되는 것은 아닙니다. 국립국어원도 여러 온라인가나다 답변에서 합성어·파생어 또는 통사적·비통사적 합성어 판정에 견해차가 있을 수 있다고 안내합니다.

따라서 학교 문법에서는 교과서의 분석 체계를 우선하고, 사전에서 접사인지 독립 단어인지 확인하는 방식이 안전합니다.

경계 사례는 억지로 단정하지 않습니다.
명확한 예로 원리를 익힌 뒤, 논란이 있는 단어는 사전과 교과서의 분석을 따릅니다.

12. 실전에서 합성어를 판별하는 네 단계

1어미 제외용언이면 활용 어미를 먼저 조어 판별에서 제외합니다.
2접사 여부 확인구성 요소 중 접사가 있다면 파생어 가능성을 먼저 봅니다.
3어근 수 확인둘 이상의 실질 형태소가 결합했는지 봅니다.
4구와 구별하나의 단어로 굳어진 결합인지 사전과 문맥을 확인합니다.
  • 합성어는 둘 이상의 어근이 결합한 단어입니다.
  • 합성어와 파생어는 모두 복합어입니다.
  • 접사가 결합했다면 합성어가 아니라 파생어일 수 있습니다.
  • 어근과 어간은 서로 다른 분석 관점의 용어입니다.
  • 합성어와 구를 구별해야 합니다.
  • 복잡한 단어는 마지막 직접 구성 요소부터 분석합니다.
  • 통사적·비통사적 합성어는 합성어의 하위 분류입니다.
  • 분석이 갈리면 교과서와 사전을 우선합니다.

13. 한눈에 정리 — 합성어는 어근과 어근의 결합이다

어미는 세는가?단어 형성 판별에서는 일반적으로 제외

접사의 참여 여부와 구의 가능성을 함께 확인하면 합성어 판별이 훨씬 정확해집니다.
